## 5. Notes on choices

- N0, N1, N2 and the shape EMA of N4 include the current frame before use. The N4 background P_bg is used before its update, as specified.
- N5 reuses the N4 state (P_bg, shape) unchanged and only replaces the scalar impulse term with max(P_i - P_bg, 0) * S2(k).
- S2(k) = |Sf(k)|^2 / mean_k |Sf(k)|^2 over the N/2+1 rfft bins of the trimmed secondary path (hS, N = 1024), computed once per source.
- N6 has its own background (log P_bg and shape) so that the clean update does not change the N4/N5 state. Its weight w_i = min(1, 2/z_i) uses z_i = P_i / P_bg6 before the update, and the effective alpha is 0.05 * w_i for both EMAs.
- The z_i column and the impulsive/non-impulsive split in Table 2 still come from the N4 background, for comparability across norms. N6 therefore uses a slightly different z for its own weighting.
- eps = 1e-6 x cumulative mean of P_i (up to the current frame), used for all normalizations.
- The N3 instantaneous Lam uses the same eps (not eps times a frame mean).
- The CMS seeds (0, 1, 2) are generated in memory with rng = numpy default_rng(seed) and are not saved.
- If a fixed or oracle run diverges (non-finite w), its ANR is reported as nan and it is excluded from best-mu selection.
