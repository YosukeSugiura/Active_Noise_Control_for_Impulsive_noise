## Abstract

Feedforward active noise control (ANC) systems for impulsive noise usually limit the effect of large error samples to keep the adaptive filter stable. However, a sudden change in the primary path also produces large error samples, and the same limitation then slows the convergence to the new optimal filter. This paper presents a frequency-domain filtered-x algorithm that does not attempt to classify the cause of a large error. Instead, it tests whether faster adaptation actually reduces the error. When the ratio of the error power to the reference power rises above its running average, a background filter is initialized with the coefficients of the foreground filter and adapted with a larger step size. The foreground filter, which generates the control signal, keeps its normal update during this trial. The background coefficients are copied to the foreground filter only if they yield a sufficiently smaller error on the same data. Otherwise, the trial is discarded, and the control signal is identical to that of the same algorithm without the trial. The update is based on a spectral-factor direction normalized by the input power of each block. During a short period after start-up and after each transfer, the error frame is recomputed with the current coefficients. We derive the mean update direction for finite block lengths and a step-size bound for the update with the recomputed error. In simulations with measured room impulse responses and ten noise types, the proposed algorithm reduced the median recovery time after a noise-source switch from 0.98 s to 0.36 s and from 1.26 s to 0.40 s, compared with the best of eight existing algorithms. Without a path change, the difference in noise reduction was −0.05 dB (95% confidence interval [−0.08, −0.03] dB). For machinegun noise, the existing algorithm recovered faster because the trial was rarely confirmed.

## 1. Introduction

Impulsive noise contains bursts whose amplitudes far exceed the background level. Typical sources include pile drivers, pneumatic hammers, and firearms. In feedforward ANC based on the filtered-x least-mean-square (FxLMS) algorithm, such a burst produces a large error sample and, consequently, a large coefficient update. A few such updates can make the adaptive filter diverge.

To prevent this divergence, previous studies have modified the update so that large samples have a limited effect. The error or reference signal is clipped at a threshold [refs], the error is compressed by a logarithmic function [refs], the squared-error cost is replaced by an M-estimator [refs], or the step size is normalized by a robust estimate of the signal power [refs]. These modifications keep the adaptive filter stable under impulsive input.

However, a large error sample is not always caused by an impulse. When the primary path changes abruptly, for example when another noise source becomes dominant, the current coefficients no longer cancel the primary noise, and the residual error increases. An update rule that limits the effect of large errors also limits the update in this situation. Consequently, the adaptive filter converges slowly to the optimal filter for the new primary path. In our evaluation with measured room impulse responses, the best of eight existing algorithms required about 1 s in median to recover after a noise-source switch (Section 6).

The difficulty is that an impulse and a path change cannot be distinguished from the error of a single block. This paper therefore takes a different approach. Instead of classifying the cause of a large error, the proposed algorithm tests whether faster adaptation actually reduces the error. When the ratio of the error power to the reference power rises above its running average, a background filter is initialized with the coefficients of the foreground filter. The background filter is then adapted with a larger step size, while the foreground filter, which generates the control signal, keeps its normal update. If the error computed with the background coefficients becomes sufficiently smaller than the error computed with the foreground coefficients, the background coefficients are copied to the foreground filter. Otherwise, the trial is discarded. Because the background filter does not contribute to the control signal, a discarded trial leaves the control signal identical to that of the same algorithm without the trial, given the same initial state and input. In contrast, a transfer confirmed without a path change does change the control signal, and we report how often such transfers occurred.

The trial is effective only if the background filter converges within a few blocks. To achieve this, we combine three elements and analyze them for finite block lengths. First, the update uses a spectral-factor direction [Elliott and Rafaely] normalized by the input power of each block. We show that, conditioned on the sequence of block powers, the mean direction does not depend on the amplitude of an isolated impulse. Second, during a short period after start-up and after each transfer, the error frame is recomputed with the current coefficients, as in the modified FxLMS algorithm [refs]. We derive a step-size bound for this update and select the step size from this bound. Third, the comparison between the two filters uses the recomputed errors, so that both filters are evaluated on the same data. The foreground–background structure itself is known from echo cancellation [Ochiai 1977, refs], and the contribution of this paper lies in its use for reconvergence in ANC and in the analysis of the combined algorithm.

The remainder of this paper is organized as follows. Section 2 reviews related work, and Section 3 formulates the problem. Section 4 describes the proposed algorithm and its analysis. Section 5 describes the evaluation framework. Section 6 reports the reconvergence after a primary path change, and Section 7 reports the cost of the trial mechanism when the path does not change.
