## 1. 定理 A：SF の平均作用と不動点

**仮定。** (A1) x は定常で、係数は固定。(A2) Λ = S_rr（正確、ε = 0、S_rr > 0 で log S_rr が可積分）。(A3) 誤差窓と参照の相互相関が、使うラグの全域で折り返しなく得られる（N → ∞ の理想フレーム）。

**主張（厳密）。** w_∞ を無限長の因果 Wiener 解とすると

    E d_n = c ( w − [w_∞]_M ),   c = M_e / N

したがって (i) 平均の不動点は [w_∞]_M、(ii) 平均作用は重み空間で c·I_M（スカラー。座標や内積によらない）。命題3（THEORY_final §2）の「近似」は、この仮定の下では厳密になる。

**証明の筋。** 相互スペクトルは S_rr W + S_rd。F^* で割ると F W + q、q = S_rd/F^*。F W は因果。P_T をかけて P_T F w + P_T q。F⁻¹ は因果（下三角）なので、出力の最初の M 個は入力の最初の M 個だけで決まる（T ≥ M）。よって

    P_M F⁻¹ P_T F w = P_M F⁻¹ F w = w,    P_M F⁻¹ P_T q = P_M F⁻¹ [q]_+ = −[w_∞]_M

（w_∞ = −F⁻¹[q]_+）。∎

**数値（thmA.py、白色入力の期待値モデル、M = 512）。**

| 確認 | 結果 |
|---|---|
| 恒等式 P_M F⁻¹ P_M F P_M = I_M | 誤差 1.3e-16 |
| N = 2048、4096、8192（M_e = 512） | ‖A − I‖₂ = 0.001、不動点と [w_∞]_M の差 −81〜−82 dB |
| N = 4096、M_e = 128 | 同上（M_e によらない） |
| N = 1024（現行、M_e = 512） | ‖A − I‖₂ = 0.069、固有値 [0.998, 1.038]、不動点の超過 −17.06 dB（[w_∞]_M は −16.92 dB） |
| N = 1024、M_e = 128 / 256 | ‖A − I‖₂ = 0.038、不動点の超過 −16.28 / −16.61 dB |

N = 2M でのずれは、ラグ M 以上の相関が折り返しで汚れることによる（(A3) の破れ）。大きさは 1/F のインパルス応答の尾で決まる。
RESULTS_prop3.md の「N = 2048、4096 では +8.7、+10.4 dB」は、そこで使った期待値モデル（closedform/sf.py の ctil）がラグ M 超の重みを N = 2M 専用の形で書いていたためで、正しい重み n₁(m) = min(M_e, N − m) を使うと、N を増やすほど理想に近づく。

### 1.1 正則化が非スカラー性の原因である（数値）

実装は Λ = Ŝ_rr + εP̄（ε = 10⁻²）を使う。このとき (A2) が崩れ、平均作用は c·I でなくなる。

| ε | h_eff/h（E / Φ、状態 i） | 非スカラー成分（E / Φ） | 固有値の範囲 | 不動点の超過 |
|---|---|---|---|---|
| 10⁻⁶ | 1.000 / 1.000 | 0.000 / 0.0000 | [0.998, 1.038] | −17.06 dB |
| 10⁻⁴ | 0.998 / 1.000 | 0.000 / 0.0000 | [0.938, 1.013] | −17.12 dB |
| 10⁻³ | 0.978 / 0.998 | 0.002 / 0.0000 | [0.589, 1.006] | −17.36 dB |
| 10⁻² | 0.872 / 0.987 | 0.042 / 0.0011 | [0.130, 0.997] | −18.91 dB |

ε = 10⁻² の行は、protoA の実測（h_eff/h = 0.876 / 0.991、非スカラー 0.044 / 0.002）を再現する。したがって、実測された非スカラー性と h_eff < h は、有限フレームではなく正則化による。固有値 0.13 のモードは S_rr の谷（二次経路の零点付近）にあり、Φ のノルムではほとんど重みを持たない（解釈。モードの位置は未確認）。
帰結：h_eff = 0.95h は設定値であり、ε の関数として上の表から決めるのが正しい。ε を小さくできれば h_eff → h で、非スカラー性は消える。

### 1.2 y 座標の内積と Φ の内積（厳密）

T = M のとき、逆因子をかける前のベクトルの平均は E y_n = c F_M v（F_M は F の先頭 M×M ブロック、v = w − [w_∞]_M）。したがって y 座標の内積は F_MᵀF_M で、

    Φ_M = F_Mᵀ F_M + H_Mᵀ H_M   （H_M は F の M 行目以降。尾の項）

F_MᵀF_M ≤ Φ_M。数値：一般化固有値は [0.135, 1.000]、中央値 1.000。‖F_M a‖²/‖a‖²_Φ は a = w_M で 1.0000、a = [w_∞]_M − w_M で 0.28。

- THEORY_vss2 §10.4 の「h_eff/h = ‖P_M F v‖²/‖F v‖²」は、平均作用の大きさではなく、この 2 つの内積の比である。平均作用は y 座標でも Φ でも c·I（定理 A）。
- y 座標の X = c²‖F_M v‖² は、Φ の超過の下界である。尾に寄った v では最大で約 1/7 まで小さく見える。推定器の X と、評価の Φ 超過を同じ量として扱ってはいけない。

## 2. 補題 B：定数は (M, M_e, B) で決まる

係数を固定したときの方向を Δ_n = E Δ_n + η_n と書く。

**B1（遅れの核、厳密に近い）。** 誤差窓のうち、ブロック n−k の B サンプルは係数 w_{n−k} の出力からなる。よって

    E Δ_n = h Σ_{k=0}^{m−1} c_k v_{n−k},   c_k = B/M_e = 1/m

二次経路の記憶で c_0 が δ だけ減り、c_m = δ が現れる（実測 δ ≈ 0.010–0.013、c_k = 0.238、0.247、0.247、0.247、0.010。RESULTS_protoA .4）。

**B2（相関時間、近似）。** η_n は誤差窓上の和である。白色化のあと、和の中身の時間相関が B より十分短ければ、η_n と η_{n−k} の相関は窓の重なりの割合 r(k) = (1 − kB/M_e)_+ に等しく、両側の和は

    τ = Σ_k r(k) = M_e / B

条件：M ≫ 1、白色化後の相関長 ≪ B。実測：τ_a = 3.96–4.01、τ_m = 3.95–3.98（m = 4。RESULTS_protoA .0）。protoC の既定値 τ_a = 3.8 は設定値。

**B3（ゆらぎの比、近似）。** 白色化した座標で、ずれによる方向のゆらぎは S = f·h²x、f = M/M_e。実測：Φ で 0.988、ユークリッドで 0.81（m = 4、M = M_e）。ユークリッドの値は内積の違いによる。

**B4（2 次の項）。** 小ステップ（hμτ ≪ 1）の再帰 x_{n+1} = x_n − 2μh x_n + μ²K_n の K は

    K = [1 + (2τ − 1) f] h² x + τ N = [1 + 2M/B − M/M_e] h² x + (M_e/B) N

M_e = M では K = (2M/B) h² x + (M/B) N（現行：8h²x + 4N）。左右の寄与が等しいこと（2τ − 1 の形）は実測（比 0.97–1.09、RESULTS_protoA .5）。
帰結（小ステップ模型、M_e = M）：定常 X_ss = μhτN / (2 − μh·2M/B)、平均 2 乗の限界 μh < B/M（現行 0.25）。

## 3. 定理 C：方向は入力の 2 次形式である

**仮定。** 係数と正規化を固定。ξ は独立な標準ガウス。Σ = diag(σ_s²)。

**主張（厳密）。** 方向の各成分は Δ_j = zᵀK_j z（K_j は対称、w にアフィン）と書けて

    E[Δ_j] = tr(K_j Σ) = Σ_s σ_s² K_j(s, s)
    Cov(Δ_j, Δ_k) = 2 tr(K_j Σ K_k Σ) = 2 Σ_{s,t} σ_s² σ_t² K_j(s, t) K_k(s, t)

証明：r も e も z に線形で、ほかの雑音源がない。ガウスの 4 次モーメント。∎

**系 C1（対角の核。厳密）。** K_j(s, s) = Σ_{t∈誤差窓} g_e(t − s) ρ_j(t − s)。g_e は z から誤差への応答、ρ_j は z から（白色化してラグ j だけずらした）参照への応答。インパルスの応答が誤差窓に収まる位置 s では、K_j(s, s) は**雑音のない勾配**（平均の方向の第 j 成分）の N/M_e 倍に等しい。不動点での残差の寄与は、Wiener の直交条件 Σ_u g_o(u) ρ_j(u) = 0 により消える。
つまり、窓に収まった孤立インパルスは、決定論的な同定信号として働く。

**系 C2（孤立インパルス。厳密）。** Σ が 1 点 s に集中すると Δ = z_s² k(s)、k(s) = [K_j(s, s)]_j。方向は決定論的で、大きさだけが z_s² に比例する。g も z_s² に比例するので、**Δ/g の分散は 0** になる（実測 10⁻²⁸〜10⁻³⁴、RESULTS_protoB）。
注意：これは「Δ/g の分散」であって、「標本 g で条件づけた Δ の分散」ではない。Δ 自体の分散は 2σ_s⁴‖k(s)‖² で 0 でない。

**系 C3（遅い尺度。厳密）。** σ_s が核の台（フレームと経路の記憶）の中で一定値 σ なら、Δ = σ² ξᵀKξ、g ∝ σ²。Δ/g の分布は σ によらず、定常な入力と同じになる。適用ステップ s/g の下で、再帰は σ の軌跡によらない（**軌跡不変性**）。
Λ の EMA の尺度が動いても、g を同じ EMA（P̄）で測るかぎり、Δ/g には Λ/P̄ の形しか残らないので成り立つ。

**系 C4（窓の中で σ が変わるとき。厳密な範囲＋実測）。** 平均の倍率 κ = E[Δ/g]/(定常値) は、σ² で重みをつけた K(s, s) の平均で、

    0 ≤ κ ≤ κ_max ≈ N / M_e   （現行 2）

g はフレーム N 全体で一様に測るのに、平均の方向は応答が誤差窓に入る位置（全体の M_e/N）だけから来るため。実測（Φ、単一パルス）：位置 @0 で 1.6×10⁻⁵、@256 で 0.123、@511–768 で 1.89–2.01、@1023 で 2×10⁻⁸（RESULTS_protoB）。
2 点のパルスでは、Δ/g のゆらぎと雑音は定常の 0.5–0.85 倍、0.16–0.62 倍（間隔と位置による）。Cov の式のとおり、ペアの間隔と位置の関数であり、参加率などの 1 つの統計量では表せない。

**帰結。**
1. インパルスを捨てる（しきい値、クリップ）必要はない。必要なのは尺度の補正 1/g だけで、孤立インパルスのブロックは雑音の少ない更新になる。従来のインパルス対策（しきい値型、FxLMP）との違いはここにある。
2. 1/g は遅い尺度で厳密、窓より短い変化では実効ステップが最大 N/M_e 倍になる。命題 E の安定条件はこの倍率を含めて立てる。
3. 変化の検出は、入力パワーで動かない量で行う（方向のパワーは g² に比例して動く）。
4. g_min = 0.25：g < g_min では適用ステップが s/g より小さくなる。安全側で、不変性は 6 dB を超えるパワー低下の区間でだけ崩れる（収束が遅くなる）。

**手法の候補（未検証）。** g を「前半・後半の半フレームのうちパワーが大きいほうの 2 倍」で測ると、κ ≤ 約 1 に抑えられる見込み。誤差窓だけで測る g（protoB の gE）は、パルスが窓の外にあるときに倍率が 3.7–74 倍になるので使えない。

## 4. 命題 D：遅れと前半のステップ

平均の再帰（補題 B1）：v_{n+1} = v_n − a Σ_k c_k v_{n−k}、a = μh。支配根を ρ(a) とする。

**D1（最速点。数値、propD.py）。** 一様な核 c_k = 1/m のとき

| m = M_e/B | a* | ρ* | 平均の安定限界 | a*·m |
|---|---|---|---|---|
| 1 | 1.000 | 0 | 2.00 | 1.00 |
| 2 | 0.343 | 0.414 | 2.00 | 0.686 |
| 3 | 0.221 | 0.575 | 1.50 | 0.664 |
| 4 | 0.164 | 0.665 | 1.17 | 0.657 |
| 6 | 0.109 | 0.765 | 0.80 | 0.652 |
| 8 | 0.081 | 0.819 | 0.61 | 0.650 |

m ≥ 2 で a* ≈ 0.66 B/M_e。h = (2B/M)(M_e/N) を入れると **μ* ≈ 0.33 MN/M_e²**（M_e = M のとき 0.33 N/M。現行 0.66）で、B によらない。実測の核（c_4 = 0.010 を含む）では a* = 0.161、ρ* = 0.671、限界 1.147。
前半の値 0.678 は a*/h_eff（h_eff = 0.95h）。h_eff の取り方で 0.64–0.74 の幅がある（§1.1）。

**D2（2 次の項への感度。近似）。** 前半は hμτ ≈ 0.64 で、補題 B4 の小ステップ展開の条件の外にある。protoC の予測モデル（遅延つきの平均＋分散 p_{t+1} = ρ²p + μ²K′x。分散の伝播は経験的な近似）では、最小点は K に '1' を入れても（full）除いても（excl1）、T = 8、16、32 のどれでも a = 0.165 で変わらない。ρ(a) が a* で折れ、その右で急に悪化するため。
したがって前半の値は「平均の遅延モデルの折れ点」で決まり、2 次の項の近似の選択（full / excl1）に鈍い。両者は近似の選択であり、理論から一方が導かれるわけではない。

**D3（遅れの見積もりへの感度。数値）。** 実効の遅れは平均の遅れ（1.5 ブロック）より大きく測られている（約 2.6。未説明）。核の平均の遅れが 2.6 だった場合（重み 0.4@2、0.6@3）、a* = 0.118、ρ* = 0.728。a = 0.161 を使うと ρ = 0.777 で、損失は小さく、安定限界（0.52）からも遠い。純遅延 3 でも ρ = 0.815。0.161 は遅れの見積もりの誤りに対して安全側ではないが、破綻はしない。

**D4（M_e の選択。近似）。** 1 ブロックあたりの x の縮み（予測モデル）：
- M_e = M（m = 4）：0.75（T = 8）〜0.68（T = 32）。
- M_e = B（遅れなし、τ = 1、f = M/B = 4）：x_{n+1} = x(1 − 2a + (1+f)a²)、最良 a = B/(M+B) = 0.2 で **0.80**。
M_e = M のほうが速い見込みだが、差は 1 ブロックあたり 0.3–0.7 dB で、M_e = M 側の値は経験的な分散モデルに依存する。実測での確認が要る。（先の査読で書いた「約 0.65」は過小で、0.68–0.75 に訂正する。）

**D5（遅れを消した SF への予測。近似、実験待ち）。** 誤差窓を現在の係数で作り直すと平均の遅れは消えるが、窓の重なりによるデータの再利用（τ = m）は残る。小ステップ模型では K = (2M/B)h²x のままで、1 歩の最良は a = B/(2M) = 0.125、縮みは 0.875 となり、利得は出ない。この模型は a = 0.125 で条件の外（hμτ = 0.5）なので、予測としては弱い。実験（atsip/nodelay）で決める。

## 5. 命題 E：安定

適用後の実効ゲインは a_n = h s_n κ_n、κ_n ∈ [0, κ_max]（系 C4。κ_max ≈ N/M_e = 2）。

- **E1（平均、一定ゲイン。数値）。** a < a_lim で安定。一様 4 項で 1.17、実測の核で 1.147。
- **E2（平均、切り替わるゲイン。数値）。** a_n ∈ {0, a, 2a} の任意の周期列（長さ 8 まで）で、a ≤ 0.47 なら成長する積がない。h = 0.25 では s ≤ 1.9。現行の上限 s ≤ 1.5 は満たす。有限長の探索であり、証明ではない。
- **E3（平均 2 乗、小ステップ模型。近似）。** a_n < B/M（現行 0.25）。前半の値 a = 0.161 は κ = 1 で満たす。κ = 2 では 0.32 で一時的に超える。ただし κ が 2 に近づくのは入力が集中する場合で、そのときゆらぎと雑音は定常より小さい（系 C2、C4）ので、最悪の組み合わせは同時には起きない。
- **設計則。** s の上限を 1.5 ではなく前半の値（a*/h_eff）に置くと、a_n ≤ a*κ_max = 0.32 に収まる。
- **限界。** 平均 2 乗の安定の厳密な十分条件は得られていない。前半は小ステップ展開の外にあり、E3 は目安である。ここが理論で最も弱い。

## 6. 推定器を使う場合（短く）

- 統計：u_n = y_n / max(g_n, g_min)、C = E⟨u_n, ū_{n−L}⟩、Q = E‖u_n‖²。1 次の式（THEORY_vss2 §9.1、係数は補題 B の定数）を (X, N) について解く。
- 条件：h_eff μ ℓ̄ ≪ 1（ℓ̄ = L + (1−β_d)/β_d = 13）。前半は 0.2375 × 0.678 × 13 = 2.09 で条件の外。実測でも、前半と経路変化の直後は X、N を大きく過大評価する（RESULTS_protoC2、C3）。
- 定常では X が N の 2–4% で、X は分解できない。N̂ は 1.03–1.1 倍で正確。
- X は y 座標の量（§1.2）で、Φ の超過の下界。
- X の上限 Q/(1+f) は Q の式の 1 次補正と矛盾する（ChatGPT の指摘。atsip/fix0 で修正中）。
- 順方向の検証（protoA の brSA：固定正規化、固定 μ ≤ 0.1）は式の骨格を支持するが、逆推定（時変の F、平滑化した統計、固定の定数）の検証ではない。
- 推定器が性能に寄与するかどうかは、アブレーション（atsip/fix0）で決める。

## 7. 命題1 の書き直し（正規化の族 Λ_a = S_rr^a P̄^{1−a} の偏り）
