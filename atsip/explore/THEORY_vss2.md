## 0. モデルと仮定

- 更新：w_{n+1} = w_n − μ_n Δ_n（ブロックの倍率 2B/M は h に含める）。v_n = w_n − w_fp。
- 入力：x = c∗z、z(t) = σ(t)ξ(t)、ξ は白色ガウス。**理論はすべて σ の軌跡を条件とする。** SαS はガウスの尺度混合なので、条件つきでは全モーメントが有限。無条件の集合平均は存在しない。
- 方向の分解（g = 1 の定常な場合）：Δ_n = (hI + H̃_n) v_n + ζ_n。
  - h = (2B/M)·c、c = M/N。B = M/4 では h = c/2 = 0.25。
  - ζ_n：最適残差による加法的な雑音。N = E‖ζ‖²。両側の相関和 τ_a（実測 3.7–3.9）。
  - H̃_n：平均 0 のゆらぎ。S = E‖H̃v‖² = f h² x、f ≈ 1（実測 0.9）。両側の相関和 τ_m（外部の実測 2.4–2.7）。

## 1. 一歩先の最適ステップ（定常、g = 1）

E⟨v_n, ζ_n⟩ = −μN(τ_a−1)/2、E⟨v_n, H̃_n v_n⟩ = −μS(τ_m−1)/2 より

  x_{n+1} = x_n − 2μh x_n + μ² K_n,  **K_n = a_0 h² x_n + τ_m S_n + τ_a N**
  **μ°_n = h x_n / K_n**

a_0 は決定論的な項の係数。1次の展開では a_0 = 1。「同じデータを τ 回使う」とみなす粗いモデルでは a_0 = τ。どちらが実機に近いかは未確定（前半の最適値が 1.1 か 0.5 かを分ける）。一歩先のオラクルで決める。

## 2. 遅延した内積が測るもの

m = n − L、L は相関が切れるラグ（L ≥ M/B）とすると

  C_n = E⟨Δ_n, Δ_m⟩ = X_n − hμ( τ_m f X_n + τ_a N ),  X_n = h² x_n
  Q_n = E‖Δ_n‖² = (1+f) X_n + N

未知数は X と N の2つ、観測は C と Q の2つなので、解ける。

  **X̂_n = ( C_n + hμ τ_a Q_n ) / ( 1 + hμ [ τ_a(1+f) − τ_m f ] )**
  **ψ_n = X̂_n / Q_n**（方向のパワーに占める「ずれ」の割合。0 ≤ ψ ≤ 1/(1+f)）
  **μ̂°_n = (X̂_n / h) / ( (a_0 + τ_m f) X̂_n + τ_a ( Q_n − (1+f) X̂_n ) )**

- 第1版の「C = 0 が最適」は、a_0 の項を落とした近似だった。前半で約 (a_0 + fτ_m)/(fτ_m) 倍の過大評価になる。上の式はこれを含まない。
- 足し込み型ではなく、(C, Q, μ) から最適値を直接出す形になる。積分状態が上限中に蓄積する問題が起きない。μ = 0 でも X̂ = C > 0 ならすぐ立ち上がるので、0 に張りつく問題も原理的に起きない。
- 照合：固定 μ = 0.1 の定常で C/Q = −0.048（実測）を入れると、ψ = 0.042、μ̂° = 0.046 ≈ μ/2。固定ステップの定常で一歩先の最適値が μ/2 になる、という理論値と合う。

### 残りのずれの指標（ω の切り替え用）

第1版と現行の実装は [C]_+/Q を使っていた。これはステップが最適に近づくと 0 になる量で、ずれを測らない。ψ_n を使う。

## 3. 入力パワーの非定常：最適ステップの形

フレーム内の σ の集中度を、参加率で表す：

  π_n = Σ_t σ_t⁴ / (Σ_t σ_t²)²  （フレーム内。一様なら約 0、1サンプルに集中すると 1）

方向の各項の、フレームのゲイン g_n に対する依存：
- 平均の項 h v：対角の項（同じサンプルどうしの積）から来る。g_n に比例。
- 雑音 ζ とゆらぎ H̃v：異なるサンプルどうしの積から来る。パワーは g_n² (1 − π_n) に比例。
  - 理由：Wiener の直交条件は、白色の入力では1サンプルのインパルス応答について決定論的に成り立つ。孤立したインパルスは、因果ラグの勾配に雑音を作らない（窓の端の打ち切りを除く）。

したがって

  x_{n+1} = x − 2μ g h x + μ² g² [ a_0 X + (1 − π)(τ_m f X + τ_a N) ]

  **μ*_n = μ°_n / ( g_n ρ_n ),  ρ_n = [ a_0 X + (1−π_n)(τ_m f X + τ_a N) ] / K_n ≈ 1 − π_n (1 − ψ_n)**

2つの極限：
- **尺度がゆっくり変わる入力（段差、バースト。π ≈ 0）：** μ* = μ°/g_n。前半も後半も、フレームのパワーに反比例させるのが最適。このとき再帰は σ の軌跡によらず、定常な入力と同じになる（**軌跡に対する不変性**）。
- **孤立したインパルス（π → 1）：** 後半は g² (1−π) ≈ 2g − 1 なので μ* ≈ μ°/2 に近づき、g にほぼよらない。前半だけ 1/g が効く。第1版以前の経験式 2x/(c[ρ(g+κ_i)x + νJ_o]) の形は、この極限にあたる。

固定ステップの損失（定常、1次）：

  x_ss(固定) / x_ss(提案) = E[ g² ρ ] / E[g]

π ≈ 0 なら E[g²]/E[g]（実測 α=1.45 で約 3、α=1.2 で約 4 だが、インパルスでは ρ が小さく、損失は出ない。段差とバーストで出るはず）。

現行の実装との違い：
- 現行は上限 min(μ, 0.5/g_n) だけで、後半（μ が小さい）では効かない。理論は、π が小さい入力では後半も 1/g_n が要るという。
- g_n < 1 のときはステップを増やす（下限つき）。
- π_n は参照のフレームから計算できる（FFT 不要、4乗和が1回）。ただし r は二次経路を通るので、インパルスが広がる。r で測った π の使い方は検証が要る。

### 裏づけの現状（弱い）

- g が上位 1% のフレームで、雑音/g² はガウスの 1/5（α=1.45 で 0.033、α=1.2 で 0.029、ガウス 0.16）。その平均 π は 0.58–0.68。向きは合うが、(1−π) だけでは 0.07 までしか説明できない。
- フレーム全体での回帰は、g² (1−π) の当てはまりが悪い（R² 0.1）。g が小さいフレームで、前のインパルスの尾が雑音を作るため。π の定義（どの窓で測るか）を直す必要がある。theory/transient/pichk.py。

## 4. GS（平均作用がスカラーでない場合）

- 平均の方向は A v、A = h T(s^{1−a})。モードごとに速さ λ_k が違う。
- C の信号成分は v^T A^T A v で、遅いモードは λ_k² で小さくなる。Φ で測った超過（重み s_k）が残っていても、C はほぼ雑音になる。GS でステップが 0 に落ちた原因。
- 無限長の理想では、C に重み W = Φ A^{-1}（ビンの重み Λ/P̄）を使えば一次項に一致する。有限長では T(s/Λ)T(Λ) ≠ T(s) で、厳密には成り立たない。時変の ω では、過去の方向が別の Λ で作られている点も崩れる。
- 前回の実験（GS-T2）は、重み、ω の制御、積分の蓄積が同時に変わっていた。重みの効果は分離できていない。
- 方針：ω を外から与えて固定し、§2 の直接形で、重みなし / C だけ / Q だけ / 両方を比べる。

## 5. 偏りと速さ：ω の切り替え

- B0（ω = 0）は速いが不動点が偏る（命題1）。幾何型は偏りが小さいが遅いモードがある。
- 切り替えの条件は「B0 の不動点までの残りのずれ」が「不動点どうしの差 x_b」と同程度になること。
- 候補（仮説）：B0 で進みながら、幾何型の方向についても ψ を測る（ψ^geo）。B0 が自分の不動点に近づくと ψ^B0 → 0 になるが、幾何型の方向は偏りの分だけ平均が残り、ψ^geo > 0 のままになる。**ω_n = ψ^geo / (ψ^geo + ψ^B0)** のような、調整値のない切り替えが作れる。
  - 追加の計算は逆 FFT が1回。切り替えが済めば止められる。
  - 一歩先の利得の比較としては厳密でない（2つの不動点が違う）。検証が要る。

## 6. 推定のループ

- 直接形：C, Q を EMA（β）で平均し、μ ← (1−γ)μ + γ μ̂°(C, Q, μ)。
- 線形化すると、遅れ d ≈ L + 1/β_d − 1 + 1/β をもつ1次のループ。離散の純遅延ループ z_{n+1} = z_n − γ z_{n−d} では、安定は γ < 2 sin(π/(4d+2))、振動しない条件は γ ≤ d^d/(d+1)^{d+1} ≈ 1/(e(d+½))。
- これは設計の目安。EMA と制約があるので、厳密な限界ではない。γ は調整値として扱い、「メタステップ不要」とは主張しない。

### 10.4 SF の平均作用：F 座標では直交射影になる

SF の平均の方向は、因果性の打ち切り P_M（ラグ 0 … M−1）を使って

  Δ̄ = c F^{−1} P_M ( F v )

と書ける（S_rr = F F*、F は最小位相。F v は因果的なので、打ち切りの前の { · }_+ は何もしない）。y = F a の座標（**y 座標**）では ‖a‖²_Φ ≈ ‖F a‖² なので

  ⟨v, Δ̄⟩_Φ ≈ c ⟨F v, P_M F v⟩ = c ‖P_M F v‖²

となり、平均作用は**自己随伴な直交射影 c P_M**（固有値 c か 0）になる。ユークリッドの座標では F^{−1} P_M F で、自己随伴でない。

帰結：
- Φ の内積では平均作用がほぼスカラーで、h_eff/h = ‖P_M F v‖²/‖F v‖²（F v のうち最初の M ラグに入るエネルギーの割合）。不動点の近くでは v が尾のラグに寄るので下がる。実測（Φ）0.98（状態 i）、0.87（状態 iii）と合う向き。
- ユークリッドでは、F^{−1} が二次経路の零点付近で打ち切りの成分を増幅し、平均作用が大きく非スカラーになる（実測 0.5）。
- **推定器は y 座標で作るべき。** SF の実装では、逆因子をかける前のベクトル y = {R* E / F*}_+ の打ち切り後が F Δ にあたるので、追加の計算なしに Φ の内積が得られる。推定（C、Q）とオラクル（Φ の超過）の内積がそろい、平均作用がスカラーになる。以前の「重みが効かない」実験は、y ではなく Φ 行列を後からかけていた（vssI）。

### 10.5 集中度の法則：方向は入力の 2 次形式

係数と正規化を固定すると、方向は入力の 2 次形式である。

  Δ = Σ_{s,t} x_s x_t K(s, t)

（R も E も x に線形。ほかの雑音源はない。）x = σ ξ とすると
- 平均：Σ_s σ_s² K(s, s)。**位置で重みをつけたエネルギー**。K(s, s) は誤差窓との位置関係で決まり、フレームの先頭と末尾で 0、誤差窓の前後で最大（protoB：@0 で 0、@256 で 0.2、@511–768 で約 2、@1023 で 0）。
- 平均のまわりの変動：対角の (ξ_s² − 1) の項と、非対角の ξ_s ξ_t の項。
  - 標本の g で条件づけると、動径方向（全体の大きさ）の変動が消える。1 点のパルスでは方向が決定論的になり、雑音もゆらぎも 0（protoB で機械精度の 0）。
  - 残るのは非対角の項で、その大きさは Σ_{s≠t} σ_s² σ_t² |K_sym(s,t)|²。**ペアの間隔と位置の関数** ω(s, t) で決まり、π では表せない（2 点の雑音：間隔 1 で 0.08、16 で 0.18、128 で 0.44）。
  - 雑音の方向（w_fp での残差）では、対角 K_ζ(s, s) ≈ 0（Wiener の直交性）。
- これはガウスの 4 次モーメントで厳密に成り立つ（近似なし）。

帰結：
- **ρ_n と π_n はやめる。** 雑音の大きさは入力の並び方に依存し、少数の統計量では予測できない。代わりに、そのブロックの方向のパワー ‖u_n‖²（y 座標）を直接使う。これは雑音の条件つきの大きさの、そのブロックでの実現値そのものである。
- **g も位置で重みをつけるべき。** 平均の項の大きさは Σ σ_s² K(s, s) で、フレームの g とは違う。実装では、平均の作用の大きさを ⟨u_n, ū_{n−L}⟩ 系の統計から推定するか、K(s, s) を近似した窓（誤差窓の前後を重くする）で g を測る。

### 10.6 手法への帰結（次の試作で確かめる）

1. 推定は y 座標の内積で行う（追加の計算なし）。
2. 推定式は 10.3 の C、Q を X、N について解き、平均作用は h_eff（y 座標ではほぼ c）を使う。
3. ステップの目標は、10.1–10.2 の遅れと 2 次の項を入れた多段の最適値。前半は遅延 LMS の最適値（μ ≈ 0.6）以下が上限になる。
4. パワーの補正は、g と ρ の代わりに、ブロックの方向のパワー ‖y_n‖² で正規化する形を試す（NLMS の「方向のノルムで割る」に近い）。

### 10.7 残る問題
