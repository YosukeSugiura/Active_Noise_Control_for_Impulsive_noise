# protoC 修正後の結果（fix0）

基準コミット `baa85203f59e5a8dddd65d5d34399281a2034dac`。`--preset final` で 8 入力 × 3 seed × 5 則の 120 ケースを実行した。各試行は 30 秒（3,750 ブロック）。

## 修正項目

1. `--preset final` で `n_early=64`、`early_k=full`、`dopt_k=excl1` とその他のモデル既定値を固定した。矛盾する値は引数エラーにし、`par.preset` に保存した。
2. `solve_xn` は連立を解いてから、負の成分を 0 に固定し、残る成分を補正後の Q 式で求める。`N < 0` かつ `b1 ≤ 0` では直前の推定値を保持し、保持フラグを記録する。
3. `par` と要求した則がそろった完了済み出力のみスキップする。`report4` は欠損、未完了、タグ間の設定不一致をエラーとし、ジョブ失敗は非ゼロで終了する。
4. 数値発散（非有限または Φ 超過が `1e8` より大きい）と増幅（`L1 last10 > 0 dB`）を全入力で個別に集計する。
5. `rsN2` の参照パワーは直近 `2M`（8 ブロック）の二乗和を直接計算する。
6. 参照フレームのパワーとその平滑値が共に 0 のとき、`g=1` とし、`g_zero` と `g_zero_count` に記録する。
7. 真の変化を時系列順に処理し、1 秒の範囲にある最初の未使用検出を対応づける。観測終端まで 1 秒未満の変化は打ち切りに数える。対応づいた検出は一度だけ使う。
8. `early_end`、`restart_detect_block`、`restart_apply_block` を 0 始まりで記録する。検出ブロックの更新には検出前に決まっていたステップを使い、次のブロックで再始動の初期値を初めて適用する。
