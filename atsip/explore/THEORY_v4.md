## 補題 F：誤差フレームを作り直した更新は、標本共分散による反復である

**仮定。** 係数以外は固定。白色化が理想（Λ = S_rr、折り返しなし）。誤差フレームは現在の係数 w_n で作り直す。誤差側の雑音はここでは 0。

**主張（厳密）。** 白色化した参照の回帰ベクトルを r_t ∈ R^M とすると

    v_{n+1} = (I − a A_n) v_n,   A_n = (1/M_e) Σ_{t ∈ 窓 n} r_t r_tᵀ,   E A_n = I,   a = μh

A_n は半正定値。窓は B ずつ進み、隣り合う A_n は (1 − B/M_e) の割合でデータを共有する。
遅れは無い（平均は v_{n+1} = (1 − a) v_n）。作り直さない場合（SF）は、A_n が過去の係数に分かれて掛かる（補題 B1 の核）。

**帰結。**

| 項目 | 内容 | 根拠 |
|---|---|---|
| F1 2 次モーメント | E‖A_n v‖²/‖v‖² = 1 + M/M_e。補題 B3 の f = M/M_e と同じ量 | 数値：M_e = 128…2048 で 4.96、3.18、1.96、1.46、1.30（予測 5、3、2、1.5、1.25） |
| F2 十分条件 | 各ブロックで a λ_max(A_n) < 2 なら ‖v‖ は増えない（重なりによらない） | 厳密 |
| F3 λ_max | M_e = M で平均 5.8。**Marchenko–Pastur の端 (1+√c)² = 4 より大きい**（回帰ベクトルが独立でなく、1 本の系列のずらしであるため）。F2 の条件は a < 0.345 | 数値 |
| F4 実際の限界 | 反復そのものの発散は a = 0.55 と 0.625 の間（M_e = M）。F2 は十分条件で、保守的 | 数値。実機の模擬（E7）は a = 0.47 で発散 0、0.625 で 5/20 発散。一致 |
| F5 最速点 | a ≈ 0.375–0.45（32 ブロックで −60〜−63 dB）。実測の最良 μ_e = 1.25–1.5（a = 0.31–0.375）と整合 | 数値 |
| F6 M_e = B | 限界は a ≈ 0.3–0.4、最速は a ≈ 0.2。M_e = M のほうが 1 ブロックあたり約 1.7 倍速い（−1.96 対 −1.17 dB/ブロック） | 数値 |

**訂正。** 先に「限界は MP の端で決まり a < 2/(1+√c)² = 0.5」と見込んだが、F3 のとおり A_n のスペクトルは MP に従わない。また、ビンごとに独立な 1 次元の反復（ペリオドグラムが指数分布）とみなす近似は、限界が a ≈ 2.7 となり実測（0.6）と合わない。モードは結合している。限界と最速点の閉じた式は得られておらず、補題 F の反復の数値で与える。

**設計への反映。**
- 前半のステップは a_e = 0.25（μ_e = 1.0）：最速点の手前で、発散の限界（約 0.6）に対して 2.4 倍、十分条件 F2（0.345）の内側。
- 定理 C の系 C4（フレーム内の急変で実効ステップが最大 N/M_e = 2 倍）と合わせると、最悪でも a = 0.5 < 0.6。μ_e = 1.25（最悪 0.625）は限界に届く。E7 で 1.25 の余裕が薄かったことの説明になる。
- g の測り方を変えて倍率を 1 以下に抑えれば（第3版 §3 の候補）、μ_e を 1.5 近くまで上げられる見込み。未検証。

## 補題 G：分割した一致度

直近 2L サンプルの誤差を、重ならない 2 つの L サンプルに分け、それぞれから方向 d_a、d_b を作る。coh = ⟨d_a, d_b⟩/(‖d_a‖‖d_b‖)。

| 場合 | 期待値 | 標準偏差 | 根拠 |
|---|---|---|---|
| 係数のずれだけ | 1/(1 + M/L)（F1 から。d = A v、E‖Av‖² = (1 + M/L)‖v‖²、2 つの窓は独立） | 約 0.04–0.05 | 数値：L = 128、256、512 で 0.195、0.334、0.505（予測 0.200、0.333、0.500）。実装の check：0.168、経路変化の実例 0.214 |
| 参照と無相関な白色の誤差 | 0 | 1/√(実効自由度)。理想は 1/√M = 0.044 | 数値：0.044（L によらない） |

- 実際の二次経路と正則化 ε = 10⁻² での実効自由度は 505/512（dof.py）。正則化では標準偏差は増えない。
- **未解決：** 実装の check では雑音側の標準偏差が 0.089 で、理想の 2 倍だった。原因は未特定（候補：参照フレームを固定した条件つきの値であること、S_rr の指数平均と当該フレームの不一致、巡回の折り返し）。E8 の記録（RESULTS_dev2_cands.csv）で確かめる。
- **設計則。** しきい値 κ = z·σ_0（σ_0 は雑音側の標準偏差、z は許す誤り率で決める）。ずれ側の平均 1/(1 + M/L) が κ から同じだけ離れるように L を選ぶ。σ_0 = 0.044 なら L = B（平均 0.2）で両側 2.3σ。σ_0 = 0.089 なら L = B では 1.1σ しかなく、L = 2B（平均 0.33、両側 1.9σ）か L = 4B（平均 0.5、両側 2.8σ）が要る。L を伸ばすと判定が (2L − 2B)/B ブロック遅れる。
- ずれと雑音が両方あるとき：coh ≈ X/(X(1 + M/L) + N_L)。経路変化の直後は X ≫ N なので上の値に近い。
