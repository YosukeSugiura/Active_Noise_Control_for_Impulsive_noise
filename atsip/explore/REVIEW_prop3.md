## 検証

- `python prop3.py check` は修正前・修正後とも成功。修正後は ND と SF のそれぞれで、`pc_s10` の2,100ブロックの実誤差、係数、Φ 超過、適用ステップ、再始動の検出および適用ブロックが P2 と一致した。係数のずれだけの誤差の coh は 0.168、白色雑音200試行の平均は −0.005、標準偏差は 0.089。f0 は濾波参照と統計まで完全一致した。
- 判定チェックでは κ = 0.1 が EN0 を棄却し、pc を通した。下表のブロックは0始まり。数値は修正後の `check` から取得した。

  | 入力 | ブロック | coh | J | 判定 |
  |---|---:|---:|---:|---|
  | EN0_s10 | 1251 | 0.005314 | 0.507768 | 棄却 |
  | pc_s10 | 1876 | 0.213804 | 0.538458 | 通過 |

- ND の `pc_s10` と `EN0_s10` で各ブロックの Frame3 の2Bサンプルをシミュレータの実誤差と照合した。前半には再構成したフレームと実誤差のフレームが異なるブロックがあり、両者が混ざっていないことも確認した。各検出の coh、J の4ブロック最大、保護区間の開始と再始動の適用を独立に再計算して照合した。SF は P2 の再構成呼び出しを失敗させる検査でも完走し、`n_rebuilt = 0` だった。
- E9 の f0.25 は位相回転、FIR の切り出し、濾波参照、Sf を照合した。真の経路と制御側のモデルは従来のシミュレータの別入力を用いる。
- `python prop3.py run --exp all --smoke --procs 2` と `python prop3.py report --smoke` は成功。seed 10、10秒で E8 の143試行、E9 の105試行、候補 CSV の16件、Markdown の表の列数を確認した。E9 の f0.25 と d1 は両方とも全15試行で発散として集計された。
- `python prop2.py check` は成功。修正対象は `prop3.py` のみで、`prop2.py` と dev1 の結果は基点の内容を維持した。

候補 CSV の `true_change` は既存の1秒の検出窓への所属を表す。誤作動・見逃しは実行した再始動と変化を1対1で対応させる。f0.25 は有限長のモデルのため、切り出しによる近似も含む。位相回転を逆変換した4倍長の系列に対して、捨てた部分の L2 ノルムは全体の6.82%。理想的な分数遅れだけを与えた場合への一般化には、有限長化の影響を切り分ける必要がある。SC の切替後の Φ 超過は dev1 と同じ白色入力の Wiener 解を基準にした参考値。
