# ATSIP 最終評価 S0 データ報告

評価用データの取得・変換・記述統計のみを実施した。

## MeshRIR S32-M441

v1.2 の NPY ZIP（3,531,528,616バイト）を配布元 MD5 と照合した。441格子点・32音源を走査し、P の直接音が S より後の候補は 214,580 組。8 組を選び、共有する NPZ の合計は 2,737,353 バイト。 [配布元](https://zenodo.org/records/10852693)

### 選別と変換

- 48→16 kHz はポリフェーズ FIR。直接音は、幾何学的な伝搬予想（343 m/s）に録音系のオフセットを足した位置の前後12サンプルで、絶対値が最大のサンプルと定義した。オフセットは格子点0で32音源のピークと伝搬予想の差の中央値（1891.15サンプル）。配布データの時刻原点を保持した。
- 候補を直接音差の降順、同点は格子点・P音源・S音源の番号順に並べた。音源と格子点は採用済みの組と共有しない。移動先も全組で重複させず、指定距離との差が0.5 mm以内にある未使用点のうち最小番号を選んだ。方向は格子点番号に従う。
- 減衰長は応答先頭から、残存エネルギー（末尾からの二乗和）が直接音位置での残存エネルギーの −30 dB 以下になる点までのサンプル数。組内の10応答を最大の減衰長にそろえて末尾を切り、float32 で保存した。差のノルムは変換・切り詰め後の未整列の応答から求めた。
- 表のインデックスは0始まり。座標は m、遅れと減衰長は16 kHz のサンプル数。直接音の絶対遅れには約118 msの共通成分がある。S1 で経路を読み込む際の共通遅れの扱いは未決定。

## 取得・利用上の制約

- MIMII は valve の1ファイルを部分取得した。原著の録音単位と取得 WAV は10秒であり、ファイル間の連続性を示す記録は確認できなかった。40秒区間は未作成。 [配布元](https://zenodo.org/records/3384388) · [論文](https://arxiv.org/abs/1909.09347)
- UrbanSound8K の jackhammer と engine_idling は各4秒を取得した。配布されるクリップは最大4秒。連続した40秒の配布ファイルはこの版にはなく、40秒区間は未作成。 [著者ページ](https://urbansounddataset.weebly.com/urbansound8k.html)
- NOISEX-92 は元の配布サイトへの接続が通らなかったため、同データの Zenodo WAV ミラーを使用した。元音声の再配布許諾は未確認。 [ミラー](https://zenodo.org/records/3921794)
- trajectoRIR は配布場所・利用条件・形式を確認し、取得は対象外とした。 [配布元](https://zenodo.org/records/15564430)
- 配布条件、引用先、再生成コマンドは [データ README](data/README.md) に記録した。

検証では、経路 NPZ・JSON と実音 WAV・CSV を別ディレクトリに再生成し、ファイルが完全一致することを確認した。

## S0b の追記

### paths16 と音源切替

S0 の8組の音源とマイク点を引き継いだ。MeshRIR 元応答を16 kHzに変換し、1880サンプルを共通に除去し、P 系4096・S 系2048サンプルに切り詰めた。near・far は現在の S より実測の直接音が16サンプル以上遅い候補から選んだ。元の P 音源とのユークリッド距離の最小・最大を取り、同距離では小さい音源番号を選んだ。**8/8組**で両方を作成し、欠番は 0。台帳を含む総ファイルサイズは 1,230,840 バイト。 [配布版](https://zenodo.org/records/10852693) · [経路台帳](data/paths16/paths16.json)

各経路欄は「音源番号 / 実測 / 幾何予想」。遅れの単位は切り詰め後の16 kHzサンプル。幾何予想は音速343 m/sの伝搬時間に S0 の録音系オフセット1891.15サンプルを足し、1880を引いて実測の時刻原点にそろえた。生の伝搬時間も台帳に収録した。差のノルムは切り詰め後の波形どうしを比較した。

### valve とジャックハンマー

- valve は MIMII public 1.0 の `6_dB_valve.zip` から、`valve/id_00/normal/00000000.wav`〜`00000003.wav` の4本を HTTP Range で部分取得し、CRC-32 と SHA-256 を照合した。 [配布版](https://zenodo.org/records/3384388)
- ジャックハンマーは SONYC-UST v2.3 の `audio-0.tar.gz` を配布 MD5 で照合し、`00_010346.wav`、`04_002110.wav`、`16_027820.wav`、`37_016642.wav` を選択した。最初の3本は配布元の合意ラベル、最後の1本は3人の「近い」ジャックハンマー注釈があり、各録音の包絡に反復ピークがあることを確認した。街頭の録音なのでエンジン音や声が混じる区間がある。CC BY 4.0。 [配布版と注釈](https://zenodo.org/records/3966543)
- FSD50K の Hammer は固定版で個別に CC0/CC BY の音源を選べるが、クリップ長は最大30秒。今回は採用した SONYC の同種4本で条件を満たしたため追加取得しなかった。Freesound の Sailor55 による CC0 の40.027秒録音は配布ページを確認できたが、公開プレビューの取得は HTTP 403 だった。 [FSD50K](https://zenodo.org/records/4060432) · [Freesound](https://freesound.org/people/Sailor55/sounds/187920/)
- いずれも10秒×4本をモノラル・16 kHzにし、10 ms の線形クロスフェードでつないだ。3回の重ね合わせ後は39.97秒なので、4000/3997倍に再標本化し640,000サンプルにした。継ぎ目の開始・終了を処理の前後で台帳に記録した。 [実音台帳](data/noise.csv)
