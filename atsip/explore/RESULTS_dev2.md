# dev2：再始動のゲート（E8）と二次経路の推定誤差（E9）

## 結論

各30秒、seed 10–14。対応のある試行で指標の絶対差が 0.1 dB 未満の場合を「差なし」とした。

### E8 再始動のゲート

- ゲートなしの ND・SF を合わせた経路変化の検出40件は、coh が −0.112087～0.593389、J が 0.023225～0.605618。それ以外の70件は、coh が −0.439598～0.119009、J が 0.504259～0.830623。ゲートありも含めた全設定の記録で同じ範囲だった。
- **coh のしきい値を置ける範囲はない。** 経路変化の最小 coh は −0.112087（SF、pcb、seed 11、2回目の変化）。それ以外の最大 coh は 0.119009（ND、ENm20、seed 13、2回目のバースト）。`coh ≥ κ` で全変化を通すには κ を前者以下にし、誤作動をすべて除くには後者より大きくする必要がある。最大 coh を出した外乱候補の J は 0.506666 で、経路変化の最大 J（0.605618）以下なので、観測した候補を対象に同じ向きの J 条件を加えても全件分離はできない。
- 検証したゲートに **誤作動0・見逃し0・発散0を同時に満たす設定はなかった**。ND の κ = 0.15 は誤作動・発散とも0件で、20件中13件を見逃した。κ = 0.10 は ND・SF とも誤作動1件・見逃し10件・発散0件。観測した J の最大値は 0.830623 で、試した J しきい値 1.0／1.5／2.0 は判定に影響しなかった。
- κ = 0.10 の ND では、ゲートなしに比べ変化直後2秒の L1 が pc で 10.86 dB、pcb の2窓平均で 11.82 dB 悪化した。SF では pc が 10.22 dB、pcb が 11.87 dB悪化した。EVpc は両方式で差なし。ND の SC はゲートなしの5/5件発散から κ = 0.10 または 0.15 で0/5件になった。変化なしの6クラスでは、同じ前半方式のゲートなしに対して全30入力で L1・Φ 超過の集計値が一致した。
