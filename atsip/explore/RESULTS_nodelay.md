# SF と誤差フレームを再構成した SF-ND の比較

## 条件と評価

- 基準コミット `baa85203f59e5a8dddd65d5d34399281a2034dac`。G, BU, PS, II300, a145, a120, pc, pcb の8クラス、seed 10–14、各30秒（3,750ブロック）。全40入力に50規則を適用した。seed 10 の8入力で1,250ブロックの短縮版を先に実行した。
- M=512、N=1024、B=128、サンプリング周波数 16000 Hz。SF と SF-ND は同じ正則化、スペクトル因子、更新係数 2B/M を使う。実誤差から実際の二次経路出力を引いて外乱を求め、現在の係数による二次経路出力を足す。L1 はシミュレータの実誤差で評価する。
- +g は各ブロックの μ に 1/max(g, 0.25) を掛ける。+early は初回のみ先頭 64 ブロックの補正前 μ を **0.530** とする。protoC.mu_early_value の既定模型（h_eff=0.2375、予測8ブロック、K=full）の c_k を (1, 0, 0, 0, 0) にした値。
- 数値発散は非有限または Φ 超過比 > 10⁸。増幅は数値発散しなかった試行で L1 last10 > 0 dB。数値発散は div_num=1、amp=0 とし、指標は空欄。対象外の経路変化窓と再始動の2列も空欄。
- L1 は既存 ANR の時間平均。ex は各試行の区間内の線形 Φ 超過比を平均してから dB 化する。以下の数値は各クラス内の有効 seed の dB 平均をクラス間で等重み平均した値。数値発散した試行は平均から除外し、有効試行がないクラスはその行の平均から除外する。増幅試行は平均に含む。

## 安定な μ の上限

| 規則 | 数値発散0件の最大 μ | 数値発散・増幅とも0件の最大 μ |
|---|---:|---:|
| SF | 0.1 | 0.1 |
| SF-ND | 0.7 | 0.7 |
| SF+g | 1 | 1 |
| SF-ND+g | 1.5 | 1.5 |
| SF-ND+g+early | 1.5 | 1.5 |

平均モデルの根の単位円交差は、SF が μh=1.147（h=0.25 で μ≈4.59）、SF-ND が μh=2（μ=8）。今回の μ 格子は最大3（μh=0.75）で、固定 μ の平均モデルの境界より低い。実験の上限は有限時間の数値発散と実誤差の増幅で決まり、平均の安定境界を直接推定する量とは異なる。+g では g に応じて実際の μ が変動する。出典は `THEORY_final.md` §3.1、`THEORY_vss2.md` §9.2、§10.1 と `protoC.rho_delay`。

## 追加計算量と実測時間

誤差スペクトルの FFT 1回と SF 方向計算の変換5回は共通。参照スペクトルの生成を含めると、SF は N 点変換7回、SF-ND は10回。SF-ND は過去 2M−1 サンプルの r=S*x と現在の w のそれぞれに N 点 rFFT を掛け、積の N 点 irFFT の有効 M サンプルを使う。追加は **N 点変換3回**（rFFT 2、irFFT 1）、**N/2+1=513 点のスペクトル乗算**（511 複素乗算と DC/Nyquist の実数乗算2回相当）、定常時の実数加減算 2M=1,024 回。畳み込みのための追加の直接 FIR 積和は0回。実測ではデータが持つ r と、シミュレータが物理誤差の生成に使う二次経路出力を共用した。ストリーミング実装で r が未生成なら、直接 FIR では別途 B×128=16,384 実数積和/ブロック。実機で二次経路出力のモデルを新たに動かす場合も、直接 FIR なら同数の積和を別途要する。

G_s10、固定 μ=0.1、30秒。1プロセス、BLAS 1スレッド、Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、x86_64。短いウォームアップの後、実行順を交互にし各5回測定した。計測区間はシミュレーション全体（実誤差生成・係数更新・Φ 評価を含む）。共通の前処理と実行後の指標集計を除いた。

|---|---:|---:|---:|---:|
| SF | 1.692 | 1.476–1.778 | 451.3 | 1.000× |
| SF-ND | 1.946 | 1.671–2.306 | 519.0 | 1.150× |

## 再現手順

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python nodelay.py check
python nodelay.py smoke
python nodelay.py run
python nodelay.py report
```

check では1ブロック分だけが非ゼロの初回フレームと、非ゼロの係数を固定した複数ブロックで、再構成方向と元の SF の方向の一致を検証する。係数が動くときは直接畳み込みで求めた固定係数の誤差スペクトルと照合する。掃引と短縮版は out/ の別ディレクトリに条件ごとに保存する。
