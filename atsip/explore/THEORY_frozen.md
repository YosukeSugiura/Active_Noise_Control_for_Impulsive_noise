# 凍結した手法と理論（2026-11-19）

査読用の 1 本。手法（§1）と、それを支える主張（§2–§8）、主張ごとの根拠の種類、未解決（§10）をまとめる。
証明の細部と数値表の全体は THEORY_paper.md（第3版）と THEORY_v4.md（追補）にあり、ここでは主張・仮定・証明の筋・根拠を載せる。第3版から変えた点は §9 に列挙する。

根拠の種類：**厳密**（仮定の下で証明がある）／**近似**（条件を併記）／**数値**（理想化した模型の計算。スクリプトを併記）／**実測**（閉ループの模擬。結果ファイルを併記）。
実測はすべて seed 10–14（設計用）。最終評価用の seed 100–119 は未使用。

## 0. 設定と記号

- フィードフォワード ANC。参照 x、二次経路 s（モデル Ŝ）、濾波参照 r = ŝ∗x、係数 w（M タップ）、誤差 e = d + s∗(w∗x)。
- 遅延なし周波数領域ブロック処理：M = 512、FFT 長 N = 1024、ブロック間隔 B = 128、誤差窓 M_e = M（直近 M サンプル）。fs = 16 kHz。
- h = (2B/M)(M_e/N) = 0.25、a = μh（正規化したステップ）。
- 入力の模型：x = c∗z、z(t) = σ(t)ξ(t)、ξ は独立な標準ガウス、σ(t) は尺度の軌跡。**解析は σ の軌跡で条件づける**（SαS はガウスの尺度混合）。SαS の時間平均の性能は予言しない。
- Φ 超過：有限長 Wiener 解 w_M に対する ‖w − w_M‖²_Φ / J_o（J_o は因果性の床）。

## 1. 手法（凍結）

ブロック n ごとに次を行う。

1. **方向（SF）**：d_n = P_M F⁻¹ P_{N/2} { R_n^* E_n / F^* }、|F|² = Λ = Ŝ_rr + εP̄（ε = 10⁻²）、F は最小位相。Elliott & Rafaely (1997, 2000) の構成で、新規性は主張しない。
2. **尺度の補正**：w_{n+1} = w_n − (s_n / max(g_n, 0.25)) (2B/M) d_n。g_n = 参照フレームのパワー ÷ その指数平均。
3. **前半**（冷間始動の最初の 32 ブロックと、再始動の検出の次のブロックから 32 ブロック）：s_n = 1.0（a = 0.25）。誤差フレーム E_n は、現在の係数で作り直す：d̂ = e − ŝ∗y（y は実際に出した制御出力）に、現在の w_n での出力 ŝ∗(w_n∗x) を足す。前半以外では作り直さない。
4. **後半**：s_n = μ_L(δ) = 2δ / (h(τ + (2M/B)δ))、τ = M_e/B = 4、δ = 0.03（μ_L = 0.0566）。
5. **再始動（試行と検証）**：
   - 検出：z_n = 誤差窓のエネルギー ÷ 直近 2M サンプルの濾波参照のエネルギー。z_n がその指数平均の 4 倍を 2 ブロック続けて超えたら検出（検出後 64 ブロックは再検出しない）。
   - 検出したブロック n0 で係数の写し w0 を取り、n0 + 1 から前半を始める。
   - 監視：n0 + 2 ≤ n < n0 + 16 の各ブロックで、最新の B サンプルの誤差を w_n と w0 の両方で作り直し、ρ_n = E(w_n)/E(w0) を計算する。ρ_n > 4 なら係数を w0 に戻して後半に戻る。
   - 判定：n = n0 + 16 で ρ_n ≤ 0.5 なら確定（前半を続ける）。それ以外は w0 に戻して後半に戻る。

設計値の一覧と決め方：

| 値 | 決め方 | 根拠 |
|---|---|---|
| ε = 10⁻² | 10⁻³、10⁻⁴ と比べて最良 | 実測 E7 |
| g_min = 0.25 | 従来値 | 未検討（§10） |
| 前半のステップ a = 0.25 | 補題 F の発散の限界（約 0.6）の 1/2.4。系 C4 の倍率 2 を掛けても限界の内側 | 数値＋実測 E1、E7 |
| 前半の長さ 32 | 32 と 64 で差なし | 実測 E2 |
| δ = 0.03 | 0.01–0.05 で L1 に差なし | 実測 E3 |
| 判定 16 ブロック、θ = 0.5、取り消し 4 | 3 種類の事象の ρ の実測の間隔の中 | 実測 E10、E11 |
| 検出のしきい値（4 倍、2 ブロック、保護 64） | 従来値 | 実測（誤作動は検証で除く） |

## 2. 定理 A：SF の平均作用と不動点（厳密）

**仮定。** 係数固定、x 定常。Λ = S_rr（ε = 0）。相互相関が折り返しなく得られる（N → ∞）。
**主張。** E d_n = c(w − [w_∞]_M)、c = M_e/N。w_∞ は無限長の因果 Wiener 解。平均作用は重み空間でスカラー c·I、不動点は [w_∞]_M。
**証明の筋。** 相互スペクトル S_rr W + S_rd を F^* で割ると F W + q。F⁻¹ は因果なので P_M F⁻¹ P_T F w = w、P_M F⁻¹ P_T q = −[w_∞]_M。
**数値（theory/v3/thmA.py）。** N ≥ 4M で ‖A − I‖₂ = 0.001、不動点の差 −81 dB。現行 N = 2M では ‖A − I‖₂ = 0.069。
**正則化の影響（数値）。** ε = 10⁻² で平均作用の固有値は [0.13, 1.0]、h_eff/h = 0.87（E）/ 0.99（Φ）。実測された非スカラー性は正則化による。
**ビン正規化の族 Λ_a = S_rr^a P̄^{1−a} の偏り（厳密、M → ∞）。** J_b(a) = ‖f^a [f^{−a} q_−]_+‖²。a² 則は a ≤ 0.5 で 0.2 dB 以内、a = 1 で 2.7 dB 過小（theory/closedform/main2.py）。

## 3. 補題 B：構造定数（近似）

係数を固定したときの方向を Δ_n = E Δ_n + η_n とする。作り直さない場合：
- B1 遅れの核：E Δ_n = h Σ_{k=0}^{m−1} c_k v_{n−k}、c_k = B/M_e（m = M_e/B）。誤差窓のブロック n−k の部分が w_{n−k} の出力だから。実測 c_k = 0.238、0.247、0.247、0.247、0.010。
- B2 相関時間：窓の重なりで η の相関は三角形、両側の和 τ = M_e/B。実測 3.95–4.01。
- B3 ゆらぎの比：f = M/M_e。実測 0.99（Φ）。補題 F1 と同じ量。
- B4 小ステップ（aτ ≪ 1）の 2 次の再帰から、定常の超過比 X_ss/N = μhτ/(2 − μh·2M/B)。これを δ について解いたものが後半の設計式。

**後半の設計式の実測（E3）。** 末尾の Φ 超過（線形）は δ = 0.01、0.02、0.03、0.05、0.1 で 0.021、0.026、0.031、0.041、0.063。δ に比例し（傾き 0.47）、切片 0.016 は不動点の偏り（§2）。傾きが 1 でない理由（N と J_o の換算）は未導出（§10）。

## 4. 定理 C：方向は入力の 2 次形式（厳密）

**仮定。** 係数と正規化を固定。ξ は独立な標準ガウス。Σ = diag(σ_s²)。誤差側にほかの雑音源がない。
**主張。** Δ_j = zᵀK_j z（K_j は対称、w にアフィン）。E[Δ_j] = tr(K_jΣ)、Cov(Δ_j, Δ_k) = 2 tr(K_jΣK_kΣ)。
**系。**
- C1：応答が誤差窓に収まる位置 s のインパルスでは、K_j(s, s) は雑音のない勾配の N/M_e 倍。不動点の残差の寄与は Wiener の直交条件で消える。
- C2：孤立インパルスでは Δ = z_s² k(s)。方向は決定論的で、Δ/g の分散は 0（実測 10⁻²⁸ 以下、RESULTS_protoB）。「Δ/g の分散」であり、「g で条件づけた Δ の分散」ではない。
- C3：σ が核の台の中で一定なら、Δ/g の分布は σ によらない。適用ステップ s/g の下で、再帰は σ の軌跡によらず定常入力と同じになる（軌跡不変性）。
- C4：σ が窓の中で変わると、平均の倍率 κ = E[Δ/g]/(定常値) は 0 ≤ κ ≤ N/M_e = 2。実測（単一パルス）0〜2.01。
**帰結。** 参照側のインパルスを捨てる・クリップする必要はなく、尺度の補正 1/g で足りる。
**実測。** 1/g を外すと、孤立インパルスの入力で μ ≥ 0.2 から発散（RESULTS_nodelay）、最終の則で 4/40 が発散（RESULTS_ablate）。1/g ありでは μ = 1.0 まで発散 0。

## 5. 命題 D：作り直さない場合の遅れ（数値。比較対象の解析）

平均の再帰 v_{n+1} = v_n − a Σ c_k v_{n−k} の支配根を最小にする a* ≈ 0.66 B/M_e（m ≥ 2。m = 4 で 0.164）。
実測の最良は a ≈ 0.125（s = 0.5）で、模型より小さい（E1）。実効の遅れ（約 2.6 ブロック）を入れた核なら a* = 0.118 で整合するが、遅れが平均の 1.5 より大きい理由は未説明（§10）。
作り直すと初期の収束が約 2 倍速い（ブロック 16 の Φ 超過：作り直しなし +12.0 dB、あり −1.6〜+2.7 dB。E1）。

## 6. 補題 F：作り直した更新は標本共分散による反復（厳密な帰着＋数値）

**仮定。** 白色化が理想。誤差フレームは現在の係数で作り直す。誤差側の雑音は 0。
**主張（厳密）。** v_{n+1} = (I − a A_n)v_n、A_n = (1/M_e) Σ_{t∈窓 n} r_t r_tᵀ（r_t は白色化した参照の回帰ベクトル）、E A_n = I。平均に遅れはない。
- F1（数値）：E‖A_n v‖²/‖v‖² = 1 + M/M_e（M_e = 128…2048 で 4.96、3.18、1.96、1.46、1.30）。
- F2（厳密）：各ブロックで a λ_max(A_n) < 2 なら ‖v‖ は増えない。
- F3（数値）：M_e = M で λ_max の平均は 5.8。Marchenko–Pastur の端 4 より大きい（回帰ベクトルが 1 本の系列のずらしで、独立でないため）。F2 は a < 0.345。
- F4（数値）：反復の発散は a = 0.55 と 0.625 の間。**実測（E7）：a = 0.47 で発散 0/20、0.625 で 5/20、0.94 で 20/20。**
- F5（数値）：最速は a ≈ 0.375–0.45。実測の最良 a = 0.31–0.375（E1）。
- F6（数値）：M_e = B では限界 a ≈ 0.3–0.4、最速 a ≈ 0.2。M_e = M のほうが 1 ブロックあたり約 1.7 倍速い。
スクリプト：theory/v4/mp.py。**限界と最速点の閉じた式は得られていない**（MP も、ビンごとに独立とみなす近似も合わない）。
**設計。** a = 0.25。系 C4 の最悪の倍率 2 を掛けても 0.5 で、限界の内側。

## 7. 補題 G：分割した一致度（ガウス入力に限る。手法には使わない）

直近 2L サンプルの誤差を重ならない 2 つに分け、それぞれから方向を作って正規化内積を取る。
- ガウス入力：係数のずれだけなら期待値 1/(1 + M/L)（数値 0.195、0.334、0.505。実測 0.10–0.24）。無相関な白色の誤差なら 0 ± 1/√M（数値・実測とも 0.044–0.05）。
- **インパルス性の入力では成り立たない**：経路変化の実測は −0.11〜0.59 で、それ以外（−0.44〜0.12）と重なる（E8）。半分ずつが少数の大きいサンプルに支配されるため。
このため、再始動の判定には使わない。否定的な結果として記録する。

## 8. 命題 H：試行の検証（近似＋実測）

検出時の係数を w0、試行中の係数を w = w0 + Δ とする。同じ区間 W の誤差を両方の係数で作り直すと、e(w) = e(w0) + ψ、ψ = s∗(Δ∗x)。

    ρ = ‖e(w0) + ψ‖² / ‖e(w0)‖² = 1 + (2 e(w0)ᵀψ + ‖ψ‖²) / ‖e(w0)‖²

- **H0（ずれがない：w0 が不動点、e(w0) = 因果性の残差 e_o ＋ 参照と無相関な外乱 v）。** W が「まだどの更新にも使われていない最新の B サンプル」なら、Δ は W より前のデータだけで決まる。v が白色なら v|_W は Δ と x に独立、e_o は過去と現在の x に直交するので、E[e(w0)ᵀψ] ≈ 0。したがって **E ρ ≥ 1**（等号は Δ = 0）。
  条件：v が白色（有色だと Δ との相関が残る）、e_o の直交は無限長の Wiener 解で厳密・有限長では近似、Ŝ = S。
- **使ったデータで測ると偏る。** W を直近 M サンプル（直前 4 回の更新に使った区間）にすると、Δ が e(w0) に合わせ込まれて e(w0)ᵀψ < 0 となり、ρ は 1 を下回りうる。
- **H1（経路変化）。** e(w0) はずれによる成分が支配的で、試行はそれを減らす。ρ ≈ (X_K + J)/(X_0 + J)。補題 F5 の速さで下がる。
- **尺度。** 分子と分母は同じ入力サンプルから作るので、入力の尺度の軌跡は比の中でほぼ打ち消される（1/g による補正は要らない）。
- **色の変化。** 入力のスペクトルが変わった直後は白色化がずれ、補題 F の仮定が崩れて大きいステップで発散に向かう。このとき ρ ≫ 1 になるので、監視で止める。

**実測（E10、E11。dB は 10 log₁₀ρ）。**

| 検出から | 経路変化（20 件） | 誤差側の外乱（30 件） | 色の変化（5 件） |
|---|---|---|---|
| 最新 B サンプル、16 ブロック後 | −25.7 〜 −9.3 | +0.7 〜 +2.2 | — |
| 直近 M サンプル、16 ブロック後 | −26.3 〜 −12.3 | −1.0 〜 −0.5 | — |
| 最新 B サンプル、4 ブロック後 | −11.7 〜 −0.4 | +0.2 〜 +1.2 | +19.8 〜 +39.9 |
| 取り消しの時点（2–3 ブロック後） | — | — | ρ = 5.7 〜 20.1 |

H0 の予言どおり、最新 B サンプルでは外乱の ρ は常に 1 より大きく、直近 M サンプルでは 1 より小さい。
**結果（E11、13 クラス × 5 seed）。** 誤作動 0、見逃し 0、発散 0。経路変化の直後の性能は検証なしと完全に一致。外乱の試行の代償は直後 2 秒の Φ 超過 +4.5〜5.3 dB、L1 は差なし（検証なしは Φ 超過 +11〜12 dB、L1 +1.3〜5.7 dB）。色の変化は直後 2 秒の L1 +0.1 dB（検証なしは 5/5 発散）。

## 10. 未解決と弱い箇所

1. 補題 F の発散の限界と最速点に閉じた式がない。重なる窓の A_n の積の解析が要る。
2. 命題 H は期待値の主張で、ρ の分布（誤り率としきい値の関係）は実測の間隔に頼っている。経路変化が小さい場合（ρ がゆっくりしか下がらない）と、外乱が有色・非定常の場合は未検証。検出器そのもののしきい値は従来値。
3. 系 C4 の倍率（最大 2）を消す g の測り方は未検証。
4. 後半の設計式の傾き（0.47）の導出。y 座標の雑音 N と J_o の換算。
5. 作り直さない場合の実効の遅れ 2.6 の原因。
6. Ŝ ≠ S：利得 0.7〜1.4 倍と −30 dB のタップ誤差では基準の手法と同程度（E9）。−20 dB と 1 サンプル遅れでは全手法が発散。作り直しと命題 H は Ŝ を使うので、理論上の扱いは未了。
7. 定理 A、C と補題 F の内容が既存の文献にあるかの確認（Elliott & Rafaely 2000 の本文、データ再利用型 LMS の解析）。
8. 実測はすべて模擬（1 組の経路、合成の入力）。最終評価（未使用の seed、実測の経路、実録音、外部の比較手法）は未実施。
