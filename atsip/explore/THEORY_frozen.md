## 0. 設定と記号

- フィードフォワード ANC。参照 x、二次経路 s（モデル Ŝ）、濾波参照 r = ŝ∗x、係数 w（M タップ）、誤差 e = d + s∗(w∗x)。
- 遅延なし周波数領域ブロック処理：M = 512、FFT 長 N = 1024、ブロック間隔 B = 128、誤差窓 M_e = M（直近 M サンプル）。fs = 16 kHz。
- h = (2B/M)(M_e/N) = 0.25、a = μh（正規化したステップ）。
- 入力の模型：x = c∗z、z(t) = σ(t)ξ(t)、ξ は独立な標準ガウス、σ(t) は尺度の軌跡。**解析は σ の軌跡で条件づける**（SαS はガウスの尺度混合）。SαS の時間平均の性能は予言しない。
- Φ 超過：有限長 Wiener 解 w_M に対する ‖w − w_M‖²_Φ / J_o（J_o は因果性の床）。

## 1. 手法（凍結）

ブロック n ごとに次を行う。

1. **方向（SF）**：d_n = P_M F⁻¹ P_{N/2} { R_n^* E_n / F^* }、|F|² = Λ = Ŝ_rr + εP̄（ε = 10⁻²）、F は最小位相。Elliott & Rafaely (1997, 2000) の構成で、新規性は主張しない。
2. **尺度の補正**：w_{n+1} = w_n − (s_n / max(g_n, 0.25)) (2B/M) d_n。g_n = 参照フレームのパワー ÷ その指数平均。
3. **前半**（冷間始動の最初の 32 ブロックと、再始動の検出の次のブロックから 32 ブロック）：s_n = 1.0。前半では尺度の補正の下限を 0.55 にする：適用ステップは s_n / max(g_n, 0.55) で、a = 0.25 / max(g_n, 0.55) ≤ 0.455。誤差フレーム E_n は、現在の係数で作り直す：d̂ = e − ŝ∗y（y は実際に出した制御出力）に、現在の w_n での出力 ŝ∗(w_n∗x) を足す。前半以外では作り直さない。
4. **後半**：s_n = μ_L(δ) = 2δ / (h(τ + (2M/B)δ))、τ = M_e/B = 4、δ = 0.03（μ_L = 0.0566）。
5. **再始動（裏で試行し、確定したら移す）**：エコーキャンセラの二重経路法（Ochiai ら 1977）を ANC に持ち込んだもの。ANC では背景の係数の誤差を二次経路のモデルで作り直す必要があり、3 の作り直しと共用する。
   - 検出：z_n = 誤差窓のエネルギー ÷ 直近 2M サンプルの濾波参照のエネルギー。z_n が、その指数平均（係数 0.05、更新前の値）の 4 倍を 2 ブロック続けて超えたら検出。検出から 64 ブロックは再検出しない。
   - 検出したブロック n0 の係数（そのブロックの更新前）の写し w_b を作る。スピーカーに出す係数 w_f は、後半のステップと通常の誤差フレームのまま続ける。
   - n0 + 1 以降、w_b を前半のステップ（s = 1.0、g の下限 0.55）で適応させる。誤差フレームは、直近 M サンプルを w_b で作り直したもの。
   - n0 + 2 以降の各ブロックで、最新の B サンプルについて ρ_n = E(w_b)/E(w_f) を計算する（どちらも作り直した誤差）。
     - ρ_n > 4、または有限でない：w_b を捨てる。
     - n ≥ n0 + 4 かつ ρ_n ≤ 0.25：w_f ← w_b と移し、以後 w_f は前半を残り（32 − 経過ブロック数）続ける。
     - n = n0 + 16 で ρ_n ≤ 0.5 なら同じく移す。そうでなければ w_b を捨てる。
   - w_b を捨てた場合、スピーカーの出力は再始動のない場合とまったく同じになる。

実装の細部（コードに合わせた記述）：Λ = max(Ŝ_rr + s_ε + εP̄, 10⁻³⁰⁰)、s_ε は累積の平均パワーに比例する小さな下限。g_n の指数平均は当該フレームを含む。冷間始動の前半は、検出器によらず最初の 32 ブロック。

## 2. 定理 A：SF の平均作用と不動点（厳密）

**仮定。** 係数固定、x 定常。Λ = S_rr（ε = 0）。相互相関が折り返しなく得られる（N → ∞）。
**主張。** E d_n = c(w − [w_∞]_M)、c = M_e/N。w_∞ は無限長の因果 Wiener 解。平均作用は重み空間でスカラー c·I、不動点は [w_∞]_M。
**証明の筋。** 相互スペクトル S_rr W + S_rd を F^* で割ると F W + q。F⁻¹ は因果なので P_M F⁻¹ P_T F w = w、P_M F⁻¹ P_T q = −[w_∞]_M。
**数値（theory/v3/thmA.py）。** N ≥ 4M で ‖A − I‖₂ = 0.001、不動点の差 −81 dB。現行 N = 2M では ‖A − I‖₂ = 0.069。
**正則化の影響（数値）。** ε = 10⁻² で平均作用の固有値は [0.13, 1.0]、h_eff/h = 0.87（E）/ 0.99（Φ）。実測された非スカラー性は主に正則化による。有限の FFT 長の寄与は上の ‖A − I‖₂ = 0.069 の程度である。
**ビン正規化の族 Λ_a = S_rr^a P̄^{1−a} の偏り（厳密、M → ∞）。** J_b(a) = ‖f^a [f^{−a} q_−]_+‖²。a² 則は a ≤ 0.5 で 0.2 dB 以内、a = 1 で 2.7 dB 過小（theory/closedform/main2.py）。

## 3. 補題 B：構造定数（近似）

係数を固定したときの方向を Δ_n = E Δ_n + η_n とする。作り直さない場合：
- B1 遅れの核：E Δ_n = h Σ_{k=0}^{m−1} c_k v_{n−k}、c_k = B/M_e（m = M_e/B）。誤差窓のブロック n−k の部分が w_{n−k} の出力だから。実測 c_k = 0.238、0.247、0.247、0.247、0.010。
- B2 相関時間：窓の重なりで η の相関は三角形、両側の和 τ = M_e/B。実測 3.95–4.01。
- B3 ゆらぎの比：f = M/M_e。実測 0.99（Φ）。補題 F1 と同じ量。
- B4 小ステップ（aτ ≪ 1）の 2 次の再帰から、定常の超過比 X_ss/N = μhτ/(2 − μh·2M/B)。これを δ について解いたものが後半の設計式。

**後半の設計式の実測（E3）。** 末尾の Φ 超過（線形）は δ = 0.01、0.02、0.03、0.05、0.1 で 0.021、0.026、0.031、0.041、0.063。δ に比例し（傾き 0.47）、切片 0.016 は不動点の偏り（§2）。傾きが 1 でない理由（N と J_o の換算）は未導出（§10）。

## 4. 定理 C：方向は入力の 2 次形式（厳密）

**仮定。** 係数と正規化を固定。ξ は独立な標準ガウス。Σ = diag(σ_s²)。誤差側にほかの雑音源がない。
**主張。** Δ_j = zᵀK_j z（K_j は対称、w にアフィン）。E[Δ_j] = tr(K_jΣ)、Cov(Δ_j, Δ_k) = 2 tr(K_jΣK_kΣ)。
**系。**
- C1：応答が誤差窓に収まる位置 s のインパルスでは、K_j(s, s) は雑音のない勾配の N/M_e 倍。不動点の残差の寄与は Wiener の直交条件で消える。
- C2：孤立インパルスでは Δ = z_s² k(s)。方向は決定論的で、Δ/g の分散は 0（実測 10⁻²⁸ 以下、RESULTS_protoB）。「Δ/g の分散」であり、「g で条件づけた Δ の分散」ではない。
- C3：σ が核の台の中で一定なら、Δ/g の分布は σ によらない。適用ステップ s/g の下で、再帰は σ の軌跡によらず定常入力と同じになる（軌跡不変性）。σ が核の台の中で変わる入力では成り立たず、その場合の扱いは C4 と実測による。
- C4（単一パルスについての主張）：孤立パルスの位置を動かすと、平均の方向に対する Δ/g の射影の倍率は 0〜2.01 の間で変わる（protoB の模擬）。g がフレーム N 全体のパワーを測るのに対し、方向に効くのは応答が誤差窓に入る位置だけであるため。一般の σ の軌跡に対する上限（N/M_e）は証明していない。
**帰結。** 参照側のインパルスを捨てる・クリップする必要はなく、尺度の補正 1/g で足りる。
**実測。** 1/g を外すと、孤立インパルスの入力で μ ≥ 0.2 から発散（RESULTS_nodelay）、最終の則で 4/40 が発散（RESULTS_ablate）。1/g ありでは μ = 1.0 まで発散 0。

## 5. 命題 D：作り直さない場合の遅れ（数値。比較対象の解析）

平均の再帰 v_{n+1} = v_n − a Σ c_k v_{n−k} の支配根を最小にする a* ≈ 0.66 B/M_e（m ≥ 2。m = 4 で 0.164）。
実測の最良は a ≈ 0.125（s = 0.5）で、模型より小さい（E1）。実効の遅れ（約 2.6 ブロック）を入れた核なら a* = 0.118 で整合するが、遅れが平均の 1.5 より大きい理由は未説明（§10）。
作り直すと初期の収束が速い（ブロック 16 の Φ 超過で約 9〜14 dB の差：作り直しなし +12.0 dB、あり −1.6〜+2.7 dB。E1）。

## 6. 補題 F：作り直した更新の形（厳密な帰着＋数値）

**仮定。** Ŝ = S。白色化が理想（Λ = S_rr、折り返しなし）。係数以外は固定。誤差フレームは現在の係数で作り直す。
**主張（厳密）。** 作り直すと、誤差窓の中の過去の係数への依存が消える。u = F⁻¹r（白色化した参照）、U_n と X_n を u と r の回帰行列（窓 n、M 列）とすると

    v_{n+1} = (I − a G_n) v_n + （基準係数での残差による加法項）,   G_n = F_M⁻¹ U_nᵀ X_n / M_e

y = F_M v の座標では G_n は A_n = U_nᵀU_n/M_e（白色化した参照の標本共分散）に、F の M タップより先の尾による項（平均 0）を足したものになる。尾の項が無視でき、残差が 0 のとき、y_{n+1} = (I − a A_n) y_n。
A_n と v_n は窓の共有で依存するので、E A_n = I から平均の再帰 E v_{n+1} = (1 − a) E v_n は従わない。

**数値（theory/v4/mp.py、tail.py。白色ガウス、3 系列、64 ブロックまで。有限時間の観察）。**
- 尾の項の影響：この二次経路の F（エネルギーの 98% が最初の 16 タップ）で G_n をそのまま使っても、減衰と増加の境目は同じ（a = 0.55 で減衰、0.625 で増加）。速さは少し遅い（a = 0.25、32 ブロックで −64.8 dB、標本共分散の模型は −69.7 dB）。
- tr(A_n²)/M = 1 + (M+1)/M_e（Wick 展開。方向ごとの 2 次モーメントは方向に依存する）。補題 B3 の f と対応。
- λ_max(A_n) は M_e = M で平均 5.8（6 行列）。Marchenko–Pastur の端 4 より大きい。非正規化のガウス模型では λ_max は有界でないので、a λ_max < 2（各ブロックで ‖y‖ が増えない十分条件）は確率的にしか満たせない。
- 減衰と増加の境目は a = 0.55 と 0.625 の間。32 ブロック後の減衰が最大なのは a ≈ 0.375。
- M_e = B では境目 a ≈ 0.3–0.4、最良 a ≈ 0.2。M_e = M のほうが理想模型で 1 ブロックあたり約 1.7 倍速い。
**閉ループの模擬（E7、P2・前半 64 ブロック・1/g あり）。** a = 0.47 で発散 0/20、0.625 で 5/20、0.94 で 20/20。E1 の最良は、ブロック 16 で a = 0.375、ブロック 32 で a = 0.3125。
**閉じた式は得られていない。** 重なる窓の積の解析（履歴つきの 2 次モーメント作用素、または Lyapunov 指数）が要る。Shin & Sayed のアフィン射影の解析、データ再利用型 LMS、Yang & Yang の MFBLMS の解析が出発点になるが、そのまま移せる安定限界は確認できていない。

## 7. 補題 G：分割した一致度（ガウス入力に限る。手法には使わない）

直近 2L サンプルの誤差を重ならない 2 つに分け、それぞれから方向を作って正規化内積を取る。
- ガウス入力：係数のずれだけなら期待値 1/(1 + M/L)（数値 0.195、0.334、0.505。実測 0.10–0.24）。無相関な白色の誤差なら 0 ± 1/√M（数値・実測とも 0.044–0.05）。
- **インパルス性の入力では成り立たない**：経路変化の実測は −0.11〜0.59 で、それ以外（−0.44〜0.12）と重なる（E8）。半分ずつが少数の大きいサンプルに支配されるため。
このため、再始動の判定には使わない。否定的な結果として記録する。

## 8. 命題 H：破棄した試行での前景出力の不変性と、係数を移す判定

**安全性（厳密、仮定なし）。** 背景の係数 w_b は、移すまでスピーカーの出力に影響しない。したがって、w_b を捨てた試行では、出力は再始動のない場合と同一である（E12：外乱と色の変化の 20 入力すべてで、誤差の波形と Φ 超過が要素単位で一致）。誤作動の代償は、検出のあと最大 16 ブロックの計算だけである。

**判定の統計量。** 最新の B サンプルを W とし、e_f、e_b を w_f、w_b で作り直した誤差、ψ = e_b − e_f = ŝ∗((w_b − w_f)∗x) とする。

    D_W = ‖e_b‖² − ‖e_f‖² = 2 e_fᵀψ + ‖ψ‖²,   ρ = 1 + D_W/‖e_f‖²

- **H0（ずれがない場合。条件つきで厳密）。** 𝒢 を、W の回帰行列と判定前の履歴とする。ψ は 𝒢 で決まる。e_f|𝒢 の分布が原点対称で、‖e_f‖ > 0、必要な期待値が有限なら、E[e_fᵀψ/‖e_f‖² | 𝒢] = 0、したがって E[ρ | 𝒢] = 1 + E[‖ψ‖²/‖e_f‖² | 𝒢] ≥ 1（等号は ψ = 0）。
  条件を満たす例：e_f が、参照と履歴から独立な白色ガウスの外乱だけからなる場合。
  満たさない場合：外乱が有色（過去の外乱から決まる w_b と W の外乱が依存する。条件つき平均 m に対し E[D_W | 𝒢] = 2mᵀψ + ‖ψ‖² で、符号は決まらない）。因果性の残差 e_o が加わる場合（e_o は回帰量に直交するが、𝒢 の下での対称性は別の仮定）。Ŝ ≠ S（作り直した誤差に共通の項 (S − Ŝ)∗y が残る）。
  **期待値の符号は、ρ ≤ 0.5 となる確率を決めない。** ρ は、誤確定と見逃しの件数で評価する判定の統計量として扱う。
- **使ったデータで測ると偏る（観察）。** 直近 M サンプル（直前の更新に使った区間を含む）で測ると、外乱だけのとき ρ は 1 を下回った（−1.0〜−0.5 dB、E10）。最新 B サンプルでは +0.7〜+2.2 dB。2 つの窓は時刻も違うので、差のすべてを合わせ込みに帰すことはできない。
- **H1（経路変化。近似）。** 経路が固定されたあと、同じ基準で測った母集団の誤差で ρ ≈ (X_b + J)/(X_f + J)（X_f、X_b は前景・背景の超過、J は共通の残差の床）。短い窓の比や、速さの予言には使わない。
- **尺度。** 分子と分母に共通の一様な振幅の倍率は、比で厳密に打ち消される。窓の中の尺度の変動と、独立な加法の外乱は残る。
- **色の変化（観察）。** SC の条件では、検出の 2〜3 ブロック後に ρ = 5.7〜20 となり、w_b は捨てられた（E11、E12）。

**閉ループの模擬（E10–E12。dB は 10 log₁₀ρ。E10・E11 はすぐ鳴らす版の記録）。**

## 10. 未解決と弱い箇所

1. 補題 F の発散の限界と最速点に閉じた式がない。重なる窓の A_n の積の解析が要る。
2. 判定のしきい値は設計用のデータで選んだ。経路変化が小さい・ゆっくりの場合、外乱が有色・非定常の場合、経路変化と外乱が同時の場合、二次経路が変わる場合は未検証。検出器のしきい値は従来値。
3. 系 C4 の倍率（最大 2）を消す g の測り方は未検証。
4. 後半の設計式の傾き（0.47）の導出。y 座標の雑音 N と J_o の換算。
5. 作り直さない場合の実効の遅れ 2.6 の原因。
6. Ŝ ≠ S：利得 0.7〜1.4 倍と −30 dB のタップ誤差では、採用した手法の判定は崩れなかった（E12）。−20 dB と 1 サンプル遅れでは、比較した全手法が発散した（E9。P3 での結果）。理論上の扱いは未了。
7. 定理 A、C と補題 F の内容が既存の文献にあるかの確認（Elliott & Rafaely 2000 の本文、データ再利用型 LMS の解析）。
8. 最終評価（seed 100–119、1600 条件、RESULTS_final.md）は 2026-11-21 に実施。事前に固定した基準（EVAL_PLAN.md 第9版 §6）との照合：
   - 速い：経路変化 4 条件すべてで、回復の中央値が外部手法の最良（APSIPA 2026 版）より短い（46/54/44/36 対 122/157/116/98 ブロック、対応差の 95% 区間は 0 をまたがない）。
   - 定常：L1 −9.03 dB、外部の最良 −8.98 dB（差 −0.05 [−0.08, −0.03]）。
   - 安全：主条件 1400 実行で発散 0。誤確定 1 件（a145・EN0・seed 112、ρ = 0.40 で移行。移行後の L1 は再始動なしより 0.11 dB 良い）。したがって「誤確定 0」とは書かず「1400 実行中 1 件」と書く。
   - 外乱で再始動なしと出力が一致：399/400。
   - Ŝ が古いマイク移動（RM-10s、付録扱い）：発散 155/200、再始動なし 153/200（machinegun の 2 件が多い）。
   - 見逃し：RS-near 83/200、RS-far 47/200、RM-10 83/200、RM-40 72/200。見逃した場合の動きは再始動なしと同じ。
   - 誤差側の外乱の直後 2 秒は、APSIPA 2026 版が 0.63 dB 良い（提案法は再始動なしと同じ）。
   設計用 seed での試行で分かった適用の条件と限界：
   - 動作帯域：入力に 100 Hz の高域通過が要る。実測の応答は約 60 Hz 以下が測定雑音の水準で、Ŝ の位相誤差が 90° を超える。filtered-x 系に共通の条件。
   - Ŝ の長さ：256 タップでは 1 組で 80〜400 Hz の位相誤差が最大 89° になり発散した。512 タップに確定（S1d）。
   - 誤差マイクが 10 cm 動いて Ŝ が古いままの場合は、45 件中 35 件で発散する（再始動なしでも同じ）。二次経路の再同定は扱っていない。
   - 騒音源の切り替えの見逃し：near で 42 件中 17 件、far で 8 件（Ŝ 256、設計用 seed）。誤差の上がり方が小さい場合で、動きは再始動なしと同じ。
   - 実測経路では M = 512 で届く上限が −12〜−13 dB（白色入力）と浅い。
