### 4b の導き直し

§3 の再帰を g について平均し（g は v と独立、小ステップ）、K ≈ τ_a N（雑音が支配的な後半）とする。

| 規則 | 収束の速さ（1次の係数） | 定常の超過 |
|---|---|---|
| 固定 μ | 2μh E[g] | μ E[g²ρ] K / (2h E[g]) |
| μ0/g | 2μ0 h | μ0 E[ρ] K / (2h) |
| μ0/(gρ) | 2μ0 h E[1/ρ] | μ0 K / (2h) |

収束の速さをそろえて比べると（μ = μ0/E[g]）

  **固定 / (1/g) = E[g²ρ] / (E[g]² E[ρ])**
  **(1/g) / (1/(gρ)) = E[ρ] E[1/ρ]**（≥ 1）

第1版は E[g] = 1 と置き、E[ρ] を落としていた。

## 第2部 改訂した仕様

### 共通事項
- **事前に決めるもの：** 各実験の主要評価量と主要窓、効果の最小の大きさ（下記）。
- **seed：** パイロット（第1版の実行）から、対応差の標準偏差 s を出す。主要比較の seed 数は n ≥ (2.8 s / δ)²（両側 5%、検出力 80%）とし、最低 10。
- **統計：** 同じ入力での対応差を seed 単位で保存し、平均と 95% 信頼区間を出す。重なったブロックは独立とみなさない（seed が単位）。
- **凍結：** E1–E5 の結果で、γ、a0、上限、π の窓、g_min を決めて凍結する。そのあと、未使用の seed（100 番台）と外部条件で最終評価を一度だけ行う。
- **記録：** 全手法で、更新直前の状態、適用した μ、ρ、上限・下限の作動、Φ 超過（更新前の値に揃える）を同じ時刻で保存する。
- **発散：** 数値発散（w が非有限、Φ 超過 > 1e8）と増音（L1 > 0 dB）を別に記録する。
- **効果の最小の大きさ δ：** Φ 超過で 0.5 dB、L1 ANR で 0.2 dB（案。第3部で合意）。

### E1 最適ステップの校正
- **目的：** §2 の推定式が、同じ遅延と平滑化のもとで、最適ステップをどこまで追えるかを校正する。
- **E1a（モーメントの直接照合）：** G、SF、固定 μ ∈ {0.025, 0.05, 0.1, 0.2}。seed を多数（パイロットで決める）回し、時刻ごとの集合平均で E⟨v, Δ⟩_Φ、E‖Δ‖²_Φ、C、Q（実装どおりの遅延・EMA）を得る。§1、§2 の式（X、N、S、τ_a、τ_m、a0）と、時刻ごとに照合する。基準は wM と SF の不動点の両方。
- **E1b（有限ホライズンのオラクル）：** 同じ状態から、内部ステップ μ_int を一定にし、適用は規則と同じ補正（1/g 等）をかけて T ブロック進める。T ∈ {1, 4, 8, 16, 32}。平均損失と終端損失を別々に最小化する。μ̂° を適用したときの損失と、最適値での損失の差も出す。
- **報告：** 相（前半・後半・pc の直後）ごとに、μ̂° がオラクルの [0.5, 2] 倍に入る割合、両者の符号（0 かどうか）の一致率、損失差。ゼロ、格子の端、無効の件数も出す。
- 一歩先の実現ごとのオラクルは診断にだけ使う。

### E2 相関の係数
- **目的：** §1 の加法項と乗法項の係数を、適応中の量として直接測る。
- **手順：** G と a145、SF、固定 μ ∈ {0.0125, 0.025, 0.05, 0.1}。多数 seed の集合平均で、E⟨v_n, ζ_n⟩ と E⟨v_n, H̃_n v_n⟩ を μ に対して回帰し、一次係数から τ_a、τ_m を得る。ζ は共通の基準係数（wM）での残差方向、H̃v は同じ尺度軌跡で条件づけた平均方向を引いたもの（平行成分を含む）。
- 凍結プローブの自己相関（第1版の E2）は参考として並べる。交差項は τ_a N + τ_m S に対する割合で報告する。ラグの打ち切り（8、12、16）への感度も見る。

### E3 ゲインと集中度の法則
- **E3a（尺度既知）：** σ_t を固定した合成入力。同じ σ 軌跡で、ガウスの実現を多数（≥ 200）取り、条件つきの平均と分散を測る。正規化は固定（Srr と P̄ を真の値で固定）、係数は不動点と v = −w_fp に固定する。
  - 総パワーを同じにして集中度を変える：1 サンプル、4、16、64、256 サンプルの持続、一様。
  - 集中度を同じにしてフレーム内の位置を変える。
  - 単発のイベントの前、本体、尾を分け、窓の外の直前のエネルギーを記録する。
  - 予測：平均の項 ∝ g、雑音 ∝ g²(1 − π)。§3 の重みが一様だという近似の誤差も見る。
- **E3b（代理の窓）：** E3a で法則が成り立った場合だけ、EMA ありの実際の入力（II300 を含む）で、3 つの代理窓を比べる。窓を選ぶ seed とイベントと、評価する seed を分ける。
- E3a で法則が成り立たなければ、§3 の (1 − π) の項は採用しない。

### E4 パワー補正の効果
- **主比較（すべて同じ直接形、初期値・平滑化・適用ステップの上限を共通）：** 補正なし / 上限のみ（min(μ, 0.5/g)）/ 全区間 1/g / 全区間 1/(gρ)。ρ は §3 の近似式と、E3a で測った値に基づく式の両方。
- **固定ステップの対照：** μ0 と μ0/g（同じ μ0）。
- **参考：** SF+ramp、SF-V2、SF-I（交絡があるので主比較にしない）。
- **入力と主指標（事前に決める）：**

  - PS：段差直後 2 s の Φ 超過の最大値と、−20 dB への回復時間。
  - BU：バーストに同期した平均の Φ 超過（同期加算）。
  - SM：全体の Φ 超過。
  - 同じ白色の実現で、尺度の変調だけを替えた対（無変調 / 持続段差 / 周期変調）を作り、対応差で比べる。

## 第3部 合意が要る点（ChatGPT への質問）

1. **δ（効果の最小の大きさ）：** Φ 超過で 0.5 dB、L1 で 0.2 dB は妥当か。
2. **E1b の主評価：** 平均損失と終端損失のどちらを主にするか。T はいくつを主にするか。
3. **E2 の μ の範囲：** 一次係数を取るのに、0.0125–0.1 で足りるか（hμτ が 0.01–0.1）。
4. **E3a の正規化の固定：** Srr と P̄ を真の値で固定すると、実際の手法（EMA）との差が出る。E3a は法則の確認に限り、E3b で実際の条件を見る、という2段構えでよいか。
5. **E4 の対の作り方：** 同じ白色の実現に変調だけをかける場合、変調で総パワーが変わる。パワーをそろえるか、そろえずに g で補正したことの効果として見るか。
6. **seed 数：** パイロットから n を決める方法（上の式）でよいか。主要比較の数をいくつまでに絞るべきか（多重比較）。
7. 第1版の実行をパイロットとして使うことに問題はないか。
