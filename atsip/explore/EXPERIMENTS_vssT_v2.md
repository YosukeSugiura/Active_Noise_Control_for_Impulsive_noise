## 試作実験（優先順）

各項目に、直す対象の式、崩れたときに見分けたい原因、それを見分ける操作を書く。

### P1. §2 推定式の修正（最優先）

- **対象：** C_n と Q_n の式、X̂、μ̂°。
- **見分けたい原因：**
  - (a) ラグの間の v の変化（実効ラグ L + 1/β_d − 1 ≈ 13）
  - (b) Q の1次の交差項
  - (c) a0 の値
  - (d) スカラー近似（平均作用が cI でない）
- **操作：**
  1. まず理論を直す：(a) と (b) を入れた C と Q の式を導く（机上）。
  2. G、SF、固定 μ ∈ {0.025, 0.05, 0.1, 0.2}、数十 seed の集合平均で、時刻ごとに E⟨v, Δ⟩_Φ、E‖Δ‖²_Φ、E[C]、E[Q] を測る（実装どおりの遅延・EMA）。直した式の各項と並べる。
  3. ラグと平滑化を変える（L ∈ {4, 8}、β_d ∈ {0.1, 0.3, 1}）。(a) が原因なら、実効ラグに比例して食い違いが変わる。
  4. ずれの基準を wM と SF の不動点で比べる。(d) は E2 の後半の v で見えた非スカラー成分で判断する。
- **オラクル：** 一歩先は曲率が ‖Δ‖² に固定されて a0 を区別できないので、a0 の決定には使わない。同じ補正方策で内部ステップを一定にして T ∈ {1, 4, 16} 進めるオラクルを、推定式の「最適値」の意味（何ブロック先を見ているか）を決める参照にする。
- **単位：** 推定式に入れる μ と、方向 u（= Δ / max(g, g_min)）に対する実効ステップを、補正なし / 1/g / 1/(gρ) のそれぞれで一致させる。補正なしの直接形が崩れなくなることを確認する。

### P2. §1 ゆらぎの係数

- **対象：** E⟨v_n, H̃_n v_n⟩ の係数（第1版の 2τ−1 か、第2版の τ_m か）。
- **見分けたい原因：** v が両側に入ることによる寄与の有無。
- **操作：** P1 と同じ集合平均の実行で、E⟨v_n, H̃_n v_n⟩ と E⟨v_n, ζ_n⟩ を μ に対して回帰し、一次係数を取る。凍結プローブの自己相関（τ_m = 2.7）と比べる。比が 2 前後なら 2τ−1 型、1 前後なら τ_m 型。
- SαS では尺度の軌跡で条件づけた f を使う（同じ軌跡で複数のガウス実現）。

### P3. §3 集中度の法則

- **対象：** 雑音 ∝ g²(1 − π)、平均 ∝ g。
- **見分けたい原因：** 法則そのもの / 標本の π（代理）/ 時変の正規化（EMA）/ 前のイベントの尾。
- **操作：**
  1. σ_t を既知で固定した合成入力、正規化を真の値で固定、係数を固定。同じ σ 軌跡でガウスの実現を数十本。総パワーを同じにして集中度を変える（1、4、16、64、256 サンプル、一様）。これで法則そのものを判定する。
  2. 同じ条件で、イベントの前・本体・尾のフレームを分けて見る。尾が雑音を作るかを判定する。
  3. 1 が成り立ったら、正規化を EMA に戻し、次に π を標本から計算する。どの段で崩れるかを見る。
- II300 で改善がなかった理由を、この順で特定する。

### P4. パワー補正の効果（手法の改善の確認）

- **対象：** §3 の最適ステップ μ°/(gρ) と、損失の式（E[ρ] を含む形）。
- **操作：** P1 で直した推定式の直接形に、補正なし / 上限のみ / 1/g / 1/(gρ) をかける。初期値・平滑化・上限は共通。入力は G、BU、SM、PS、a145、a120、II300。seed は 1–3。
  - 損失比は、規則ごとの式（収束の速さをそろえたもの）で予測して並べる。
  - PS は段差直後の最大悪化と回復時間、BU はバースト同期の超過で見る。
- 予測と外れた入力があれば、その入力で P3 に戻る。

### P5. GS の重み（P1 の後）

- **対象：** §4。C の重み Λ/P̄ で、遅いモードのずれが C に現れるか。
- **操作：** 固定 ω で、速いモードだけ / 遅いモードだけのずれを与えた状態を作り、同じ状態で、重みあり・なしの C と、実際の Φ 超過の下がり方を比べる（一歩先、凍結）。
- 制御則の比較（積分型か直接形か）は、重み・ω・初期値・上限をそろえて別に行う。

### P6. 切り替えの指標（探索）

- **対象：** §5。
- **操作：** ψ^B0 が B0 の不動点までの距離を追うか、B0 の収束後に ψ^geo が正に残るかを、別々に見る。交差の時刻を偏りの時刻と結びつける仮説は取り下げる（交差項 2⟨v_B, b⟩_Φ が残るため）。
- 結果しだいで §5 を作り直す。
