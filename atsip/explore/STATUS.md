## 結果
- 定理 A：理想条件（正確な S_rr、折り返しなし）で、SF の平均の方向は厳密に c(w − [w_∞]_M)。平均作用は c·I、不動点は [w_∞]_M。数値で確認（N ≥ 4M で誤差 0.001、不動点の差 −81 dB）。
- 実測された非スカラー性と h_eff < h は、正則化 ε = 1e-2 が原因（ε = 1e-2 で h_eff/h = 0.872 / 0.987、非スカラー 0.042 / 0.0011 を再現）。
- RESULTS_prop3.md の「N > 2M で悪化」は、期待値モデルの重みが N = 2M 専用だったため。正しい重みでは N を増やすほど理想に近づく。
- y 座標の内積は F_MᵀF_M ≤ Φ_M（一般化固有値 0.135–1.0）。X は Φ 超過の下界。
- 補題 B：c_k = B/M_e、τ = M_e/B、f = M/M_e。K = (2M/B)h²x + (M/B)N（M_e = M）。
- 定理 C：E Δ = tr(KΣ)、Cov = 2tr(KΣKΣ)。孤立インパルスで Δ/g の分散 0、遅い尺度で軌跡不変、窓内の変化で平均の倍率は最大 N/M_e = 2。
- 命題 D：a* ≈ 0.66 B/M_e（m ≥ 2）。前半の値は ρ(a) の折れ点で決まり、full / excl1 の選択に鈍い。
- 命題1：a² 則は a ≤ 0.5 で 0.2 dB 以内、a = 1 で 2.7 dB 過小。
