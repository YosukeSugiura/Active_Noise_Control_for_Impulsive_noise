# 提案法と理論のまとめ（レビュー用、2026-11-18）

THEORY_vss2.md（§0–11）と DERIVATION_vss.md の内容を、最終形に整理したもの。各主張に、根拠の種類（厳密 / 近似 / 実測）と、根拠のファイルを付ける。
再始動の判定（§3.5）は実験中で、結果が出たら更新する。

## 1. 問題設定

- 遅延なし周波数領域 FxNLMS。M = 512、N = 1024、B = 128、fs = 16 kHz。誤差フレームは最後の M サンプル。二次経路は非最小位相。Ŝ = S。
- 入力は分離可能な進化スペクトル x = c ∗ z、z(t) = σ(t) ξ(t)、ξ は白色ガウス。**理論は σ の軌跡で条件づける。** SαS はガウスの尺度混合なので、条件つきでは全モーメントが有限になる。無条件の集合平均は扱わない。
- スペクトル包絡の変化は理論の外（評価で別に扱う）。
- 目的：入力パワーが非定常でも、条件ごとの再調整なしに速く収束し、定常の超過が小さいこと。

## 2. 正規化と偏り（既存の理論、THEORY_MEMO.md、RESULTS_prop3.md）

- 正規化の族 Λ_a = S_rr^a P̄^{1−a}。因果性の打ち切りによる不動点の偏り J_b(a) ≈ a²‖H_{log f} q_−‖²（命題1、近似。数値と 0.3 dB 以内）。
- 固有値の範囲 λ ∈ c[s_min^{1−a}, s_max^{1−a}]（補題2、Grenander–Szegő）。
- SF（S_rr の最小位相因子 F で正規化）は、有限の M で打ち切った無限長 Wiener 解に収束する。超過は ρ^{2M} で減る（命題3、近似。0.05 dB 以内）。
- GS は SF の計算を軽くした代替（Λ を混ぜる）。ステップ則の理論は、現時点で SF についてのみ。

## 3. ステップ則（今回の主題）

### 3.1 更新は遅延 LMS である（近似、実測で確認）
誤差フレームは過去 4 ブロックの係数の出力からなるので、平均の方向は E Δ_n = h Σ_k c_k v_{n−k}（c_k ≈ 1/4、k = 0…3）。平均の再帰 v_{n+1} = v_n − μh Σ c_k v_{n−k} の支配根 ρ(μh) が収束を決める。
- 平均を最速にする μh = 0.161（μ ≈ 0.68）。平均の安定限界 μh ≈ 1.15。
- 一歩先の最適値（μ ≈ 2）は遅れを無視した値で、実際には遅い。
- 根拠：RESULTS_protoA.md（.4、遅れの重み c_k）、THEORY_vss2.md §10.1。
- 未解決：方向への実効の遅れは平均の遅れ（1.5 ブロック）より大きい（約 2.6）。ゆらぎと過去の更新の相関による。

### 3.2 2 次の再帰（近似、実測で確認）
  x_{n+1} = x_n − 2μh x_n + μ² K_n,  K_n = [1 + (2τ_m − 1) f] h² x_n + τ_a N
- ゆらぎの項は、左右 2 つの寄与がほぼ等しい（実測比 0.97–1.09）ので 2τ_m − 1 になる。τ_a ≈ 3.8、τ_m ≈ 4、f ≈ 0.85。
- 根拠：RESULTS_protoA.md（.5）、THEORY_vss2.md §10.2。

### 3.3 推定の統計（近似、実測で確認）
遅延した内積 C_L = ⟨u_n, u_{n−L}⟩ と方向のパワー Q の期待値は、ずれ X と雑音 N の 1 次式で、実測の平均作用を使えば全状態・全ラグで実測とほぼ一致する。
- 根拠：RESULTS_protoA.md（.1 の brSA 列）、THEORY_vss2.md §9.1、§10.3、§11。
- 限界：前半（64 ブロックまで）と経路変化の直後は、平滑化の遅れで X、N を 4–1700 倍に過大評価する。定常では X が N の 2–4% しかなく、X は分解できない（N は 1.03–1.1 倍で正確）。推定が理論どおり働くのは中盤だけ（RESULTS_protoC2.md、RESULTS_protoC3.md）。

### 3.4 y 座標（厳密に近い、数値で確認）
SF の平均作用は、F 座標で自己随伴な直交射影 c P_M になる（Δ̄ = c F^{−1} P_M F v）。y 座標の内積は Φ の内積に一致し、平均作用はほぼスカラー（非スカラー成分 2–13%、ユークリッドでは 20–24%）。実装では逆因子をかける前のベクトルを使うので、追加の計算はない。
- 根拠：THEORY_vss2.md §10.4、数値の確認はセッション中（状態 i–iii）。

### 3.5 入力パワーの非定常（厳密、ガウスの 4 次モーメント）
係数と正規化を固定すると、方向は入力の 2 次形式 Δ = Σ x_s x_t K(s, t)。
- 平均の大きさは位置で重みをつけたエネルギー Σ σ_s² K(s, s) で決まる。
- 平均のまわりの変動は、ペアの間隔と位置で決まる。参加率 π では表せない。
- 標本の g で条件づけると、孤立したインパルスでは方向が決定論的になる（雑音 0、実測で機械精度の 0）。
- 帰結：(i) ステップに 1/g の補正をかける（全区間）。(ii) 変化の検出は、方向のパワー（g² に比例）ではなく、入力パワーで動かない量で行う。
- 根拠：RESULTS_protoB.md（標本の g で条件づけた表）、THEORY_vss2.md §10.5。

### 3.6 最終の則
1. 方向：SF。
2. 統計：y 座標の u_n = y_n / max(g_n, 0.25)。C、Q は EMA（β = 0.05）。
3. 推定：§3.3 の式を X、N について解く。
4. 目標：遅れ（§3.1）と 2 次の項（§3.2）を入れた、8 ブロック先の 2 次モーメントを最小にするステップ（スカラーのモデルで格子探索）。
5. 更新：μ_state ← (1 − γ)μ_state + γ·目標、γ = 0.03。適用 μ = μ_state / max(g, 0.25)。
6. 前半：最初の 64 ブロックは μ_state = 0.678（雑音 0 での遅延 LMS の最適値。調整なし）。
7. 再始動：変化を検出したら、統計を初期化し、前半の値に戻す（判定の量は実験中）。

調整値として残るのは γ と、再始動の判定のしきい値。

### 3.7 性能（3 seed、RESULTS_protoC3.md）
前半の理論値ありで、L1 ANR の全体はすべての入力で SF-V2（調整した旧版）と同等以上。最初の 1 秒の超過は 1.6–3 dB 小さい。再始動ありでは、経路変化の直後が 5–7 dB 良い（誤作動の修正前）。
