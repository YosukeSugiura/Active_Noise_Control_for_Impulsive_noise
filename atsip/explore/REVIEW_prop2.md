## 検証

- `python prop2.py check` 成功。SF は `pc_s10` の2,100ブロックで `e`、`w`、`ex`、適用ステップ、再始動の検出・適用ブロックが既存則と完全一致した。再始動は0始まりのブロック1876で検出し1877で反映した。ND の64ブロックと Ŝ = S の明示指定も完全一致した。qstop0.8 の検証ケースでは27ブロックで前半が終了した。
- `python protoC.py check --preset final`、`python nodelay.py check`、`python nodelay_early.py check` は成功。ablate に独立した check サブコマンドはなく、既存の完全一致確認を含む `python ablate.py run --smoke --procs 2` で240試行が正常終了した。
- `pcb_s10` の P2-ND（μ_e = 1.0、fixed64、δ = 0.03）で、実誤差の絶対値の EMA をサンプル単位で再計算した。L1 whole −29.70671801 dB、first5 −28.63277186 dB、last10 −29.44273679 dB、2イベントの L1_ev −26.76271800 dB、ex_ev 19.61277311 dB が `score()` と一致した。実誤差と2M参照の二乗和から0始まりの検出ブロック1251、2501を再現した。誤作動0・見逃し0、前半64ブロックが3回、再構成192回も一致した。同じ入力の検出列を誤作動1・見逃し1になるよう置き換え、集計結果を確認した。
- E1 のクラス等重み、32ブロックの目的値、発散・増幅の除外と、E2 の ND 限定、誤作動・見逃しの除外、0.02 dB の境界の内外を人工データで確認した。発散と1ブロックの試行を混ぜたレポートでは欠測が「—」と CSV の空欄になった。
- E5 は seed 10 の全6クラスで入力を照合した。誤差マイク側の外乱の付加区間、EVpc の15秒の経路変化、SC の極0.9を確認した。外乱のレベルと SC の同一パワーは生成過程の分散で規定され、有限長の実測値は揺らぐ。seed 10 の SC の切替前後の入力パワー差は −0.052 dB。
- E6 は G・seed 10 の全5モデルで真のプラント出力とモデルの出力を別々に再計算した。モデルによる濾波参照と Rall、誤差再構成の二次経路出力、真の経路による実誤差を確認した。タップ誤差 n20 は経路全体で誤差エネルギー比が −20 dB。

- `python prop2.py run --exp all --smoke --procs 2` と `python prop2.py report --smoke` は成功。seed 10、10秒で全318行と Markdown 表の列数を確認した。選択は SF 0.5、ND 1.25、fixed32。数値発散は E6 の1サンプル遅れで6件、E7 で3件を記録し、イベント直後の観測窓は欠測として出力した。

## 集計上の留意点

- E2 の適格条件は発散・増幅・誤作動・見逃しがすべて0件。10秒のスモークで経路変化を含む試行の検出性能は評価できない。本試行では `protoC.restart_stats` の既定どおり経路変化後1秒を検出窓に使う。
- E5 の L1 は外乱を含む非制御時の `d` が分母。SC の切替後の Φ 超過は既存の白色入力用 Wiener 解を基準にした参考値。E7 は `plan()` どおり ε と μ_e 倍率を個別に掃引する。
