# 推定器（SF-V / GS-V）と過渡理論の接続：机上の導出

2026-11-17。数値での確認はまだ。確認する項目は最後にまとめる。

## 0. 記号

- 更新：w_{n+1} = w_n − μ_n Δ_n。v_n = w_n − w_fp（いまの正規化の不動点からのずれ）。
- 方向の分解：Δ_n = h g_n v_n + ζ_n。h = c/2（c はフレーム重なりの係数、約 0.5）。g_n は参照のフレームパワーと平均パワーの比。
- x_n = E‖v_n‖²。雑音の相関係数 ρ_ζ(k) = E⟨ζ_n, ζ_{n+k}⟩ / E‖ζ_n‖²。
- τ = Σ_k ρ_ζ(k)（両側の和。雑音の相関時間をブロック数で表した量）。

## 1. 最適ステップは q_n の定数倍になる

恒等式 x_{n+1} = x_n − 2μ E⟨v_n, Δ_n⟩ + μ² E‖Δ_n‖² を使う。

フレームが重なるので、v_n は過去の雑音 −μ ζ_{n−k} を含み、ζ_n と相関する。ステップがゆっくり変わるとき

  E⟨v_n, ζ_n⟩ = −μ Σ_{k≥1} ρ_ζ(k) E‖ζ‖²

となる。これを入れると、g_n = 1 のとき

  x_{n+1} = x_n − 2μ h x_n + μ² [ S_n + τ N ]

S_n は x_n に比例する項（信号に依存するゆらぎ）、N = E‖ζ‖² の加法的な部分。
収束の後半（S_n ≪ N）では

  μ*_n = h x_n / (τ N)

一方、推定器の量は、ラグ L で雑音の相関が切れていれば

  C_n → h² x_n,  Q_n → S_n + N,  q_n = C_n / Q_n → h² x_n / N（後半）

したがって

  **μ*_n = q_n / (h τ) = κ* q_n,  κ* = 2 / (c τ)**

κ* は ρ、ν、J_o のどれにもよらない。フレームの構成だけで決まる。

### τ の値

誤差フレームは最後の M サンプルで、ホップは B。k ブロック離れた2つの誤差フレームは M − kB サンプルを共有する。雑音の相関が共有部分に比例するなら

  ρ_ζ(k) = (1 − kB/M)_+,  τ = M/B = 4

c = 0.5 なら **κ* = 1.0**（c = 0.42 なら 1.19）。調整で選んだ κ = 1 と一致する。

### ラグ L

雑音の相関が切れる最小のラグは M/B = 4。参照フレームの重なりまで見ると N/B = 8。採用した L = 8 は安全側。L = 4 まで縮められる可能性がある。

### κ に対する感度

κ = θ κ* とすると、後半の再帰は x_{n+1} = x_n − θ(2−θ) h² x_n² / (τN) となり

  x_n ∝ 1 / (θ(2−θ) n)

θ = 0.5 から 1.5 の範囲で、損失は 1.25 dB 以下。調整で谷が平らに見えたことと合う。
μ_n は 1/n で減り、μ_lo で止まる。検出器なしで減衰するのはこのため。

## 2. 追従の遅れによる偏り（前半）

C_n は ⟨v_n, v̄_{n−L}⟩ を測る。v が速く縮む間は、古い v のほうが大きい。遅れは D = L + 1/β_d − 1 ブロックなので

  C_n / (h² x_n) ≈ (1 − h μ ĝ)^{−D}

μ = 0.3、h = 0.25、D = 17 で約 3.6 倍の過大評価になる。前半では q_n が大きく出て、μ_hi で切られる。
補正するなら q_n に (1 − h μ_n)^{D} を掛ける。補正すれば μ_hi を理論値に近づけられる可能性がある。

## 3. 前半のステップと上限（未確定）

フレームが独立だとした再帰では

  μ*_n = 2 x_n / ( c [ ρ (g_n + κ_i) x_n + ν J_o ] )

前半は μ* ≈ 2 / (c ρ (g_n + κ_i))。ρ = 2、c = 0.5、κ_i = 0.9 で、g_n = 1 のとき 1.05。

調整値は μ_hi = 0.3、χ = 0.5 で、どちらもこの約 1/4。
モデルの最適スケジュールを実機に流した結果も同じ向き（最初の5秒の超過は、予測 0.69 dB に対して、等倍で 1.53 dB、半分で 1.11 dB）。モデルの μ² の項が、大きいステップで小さすぎる。

仮説：信号に依存するゆらぎにも τ が掛かる（ρ を ρτ に置き換える）。そうなら μ_hi ≈ 0.26、χ ≈ 0.5 になり、調整値と合う。
ただし、ゲインが τ ブロック続くだけなら安定限界は変わらない（(1 − μhg)^τ の安定条件は1ブロックと同じ）。安定限界の実測（SF で 0.6）とも、この仮説だけでは整合が取れない。ここは測定で決める。

## 4. GS の切り替え（q_lo、q_hi）

q_n が測るのは「いまの正規化の不動点」までの距離で、Wiener 解までの距離ではない。1ステップの貪欲則が GS で使えなかった理由はここにある（ω を動かすと不動点が動く）。

切り替えの基準：ω = 0（完全な正規化）での残りのずれ x が、偏りの差 x_b = J_b(1) − J_b(a) まで下がったら、幾何型に移る。それ以上続けても、得は 3 dB 未満。

  q_sw = x_b / ( ρ(1+κ_i) x_b + ν )

a = 0.5 で x_b = 10^{−0.08} − 10^{−0.96} ≈ 0.72。ρ(1+κ_i) = 3.8、ν ≈ 3.8（ガウスの定常値から逆算。粗い）で q_sw ≈ 0.11。
調整値の q_lo = 0.05、q_hi = 0.2 の幾何平均は 0.1 で、合う。ν の値は要確認。

## 5. a の食い違い

矛盾ではない。前提が違う。

- 固定ステップ（μ = 0.1、30 秒）：小さい a は遅いモード（λ ∈ c[s_min^{1−a}, s_max^{1−a}]）のせいで全区間で損をする。a ≈ 0.45–0.8。
- 傾斜つき（最初は ω = 0）：速い収束は完全な正規化が受け持つ。a が効くのは、B0 の不動点から a の不動点へ移る最後の区間だけ。小さい a の損が減り、偏りの小ささが勝つ。a ≈ 0.25。

a* は評価する時間の長さで決まり、長いほど小さくなる（極限は a = 0 で偏りなし）。
ただし a = 0.25 は、μ² の項を直す前のモデルで出した値。3 を決めたあとで、同じモデルで計算し直す。

## 6. 先行研究との違い

発想が近いもの：
- Mathews & Xie 1993：連続する勾配の内積 e(n)e(n−1)x^T(n−1)x(n) でステップを増減する。
- Aboulnasr & Mayyas 1997：誤差の遅延積 e(n)e(n−1) の平均を使う。
- Shin, Sayed & Song 2004：正規化した勾配ベクトルの平均 p のノルムで μ = μ_max‖p‖²/(‖p‖² + C)。

違い：
1. 比 q = C/Q が最適ステップの定数倍になり、定数 κ* = 2/(cτ) がフレーム構成から決まる。メタステップも、SNR に依存する定数 C も要らない。
2. 遅延 L をフレームの重なりから決め、雑音どうしの積の平均をゼロにする。
3. g_n による正規化と上限で、入力パワーの非定常に対応する。
4. 同じ量で正規化（ω）も切り替え、偏りを制御する。対応する先行研究はない。

「勾配の相関でステップを決める」発想そのものは既知。書誌は要確認。

## 9. 係数 c

方向は、誤差窓（最後の M サンプル）での相互相関を、N サンプルのフレームのパワーで割ったもの。したがって

  **c = M/N = 0.5**

実測は SF で 0.48–0.50、B0 で 0.50。差は正則化と因果性の打ち切りによる。
0.42 は SαS で白色のプローブを使ったときの値。EMA のパワーがインパルスで押し上げられ、E[g] < 1（α=1.45 で 0.94、α=1.2 で 0.88）になる分と、正則化の分で下がる。c そのものの食い違いではない。

## 10. τ と L（照合済み）

定常での方向の雑音の相関：ρ_ζ(k) = 1, 0.73, 0.48, 0.22, −0.02, …（k ≥ 4 でほぼ 0）。三角形で、τ = 3.7–3.8。
L = 4 で足りる。

## 11. 信号に依存するゆらぎ（前半の μ² の項）

1フレームについて、白色ガウスの4次モーメントから

  E‖H_n v‖² = c² (1 + f) ‖v‖²,  f = (タップ数 + 1) / (誤差窓の長さ) ≈ 1

タップ数と誤差窓がどちらも M なので 1 + f ≈ 2。実測は 1.88–1.90。

フレームの重なりを入れる。v_n は過去の H̃_{n−k} を含むので、1次の展開で

  x_{n+1} = x_n − 2ηc x_n + η² c² [ 1 + f (2τ − 1) ] x_n + η² τ N

加法的な雑音には τ、ゆらぎには 2τ − 1 が掛かる。f = 1 のとき 1 + f(2τ − 1) = τ(1 + f) となり、両方に同じ τ が掛かる形になる。
このとき最適ステップは、過渡の全体で

  **μ*_n = κ* q_n,  κ* = 2/(cτ) = 2NB/M² = 1.0**

モデルで ρ = 2（グリッドの端）が選ばれたことと、モデルの最適スケジュールが実機で大きすぎたことは、この τ の欠落で説明できる（モデルは 3.8、正しくは約 7.5）。

### g_n を含む統一則

条件つき（g_n が既知）の最適値は

  **μ_n = κ* q_n / ( 1 + (1 + f)(g_n − 1) q_n )**

- g_n = 1 で κ* q_n。
- g_n が大きいと κ* / ((1+f) g_n) = 0.5 / g_n。調整値 χ = 0.5 と一致。
- 前半（q_n → 1/(1+f)）の上限は κ*/(1+f) = 0.5。調整値 μ_hi = 0.3 より大きい。

clip と上限の2段を、この1式に置き換えられる。定数は κ* = 2NB/M² と 1 + f = 2 だけ。
前半の 0.5 と 0.3 の差は未解決（立ち上がりの g_n、1次の展開の限界、2節の遅れの偏り）。

## 12. 訂正：ノルムの不一致

1節の「κ* = 1 が調整値と一致」は、そのままでは成り立たない。

- 超過 MSE は Φ ノルム（v^T Φ v）で測る。推定器はユークリッドの内積を使っている。
- SF の方向の雑音は、ユークリッドでは二次経路の零点付近のビンに集中する。そこは残差を消せないので S_o が大きく、1/s で増幅される。
  - 予測：ユークリッドの雑音は Φ 重みの 17 倍。s < 0.1 のビン（全体の 10%）が 94% を占める。
  - 実測：15.2 倍。
- その結果、いまの q_n は Φ で見た値の約 1/15。後半の q_n は 0 から 0.02 の間で揺れ、μ はほぼ μ_lo に張りつく。後半の性能は μ_lo が決めていて、κ は効いていなかった。調整で κ の谷が平らだった主な理由はこちら。
- κ* q が最適になるのは、内積を Φ で重みづけたときだけ。

### 修正案（計算量は増えない）

- **SF：** 方向は Δ = F^{-1} y、y = {R*E/F*}_+。‖Δ‖²_Φ ≈ ‖y‖² なので、Δ の代わりに途中のベクトル y の内積を使う。追加の計算なし。
- **GS：** 平均方向が A = c T(s^{1−a}) なので、C には重み s^a、Q には重み s を使う。Srr はビンごとに手元にある。因果性の打ち切りとの順序は実装で要確認。

これで SF と GS の両方で κ* = 2NB/M² になる。雑音の大きいビンが抑えられるので、q_n の揺れも減る見込み。

### GS の κ = 2 について

ユークリッドのままだと、最適な κ は κ* γ_o γ_V になる。a = 0.5 で γ_o = 1.37、γ_V は前半 1.15、後半 0.5 以下。前半で約 1.6 となり、調整値 2 と合う。SF は γ_o が 15 と大きいが、前半は上限、後半は下限で決まるので見えなかった。

## 13. 検証（iii）（iv）の見直し

- **（iii）段差で安定限界が下がらない：** 予測の立て方が誤り。Srr は EMA（時定数 20 ブロック）なので、段差のあと g_n が大きいのは有限のブロック数だけ。誤差は一時的に増えるが、発散はしない。安定限界を決めるのは g の定常な統計。試すべき予測は「段差直後の誤差の増幅率 Π_k |1 − ηc g_k|」。
- **（iv）超過の符号：** 1次の定常値は x_ss = μ τ n̄ / (4 c̄) で、g のばらつきには直接よらない。クラスごとの実測値（SF：τn̄ = 0.607 / 0.471 / 0.430、c̄ = 0.492 / 0.499 / 0.484）を入れると、ガウス比で α=1.45 は −1.2 dB、α=1.2 は −1.4 dB。インパルス性が強いほど良くなり、実測の向きと合う。前の予測は2次の項だけを見ていた。n̄ がなぜ下がるかの分解は未了。
- **（ii）不動点の不変性：** 設計の問題で、理論の変更はない。段差を最後まで保つ条件と、同じ実現で段差の有無を比べる条件に直す。
