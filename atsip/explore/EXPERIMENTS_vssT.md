# 検証実験 E1–E6 の目的と仕様（THEORY_vss2.md の検証）

2026-11-18。実装は vssT.py / vssT_lib.py（コミット 4e914fc）、実行手順は RUN_vssT.md。
この文書は「何を確かめ、何をもって合否とするか」を定める。結果を見る前に書いている。

## 0. 共通の設定

### 系と手法
- 遅延なし周波数領域 FxNLMS。M=512、N=1024、B=128、fs=16 kHz、30 秒（3750 ブロック）。誤差フレームは最後の M サンプル。
- 二次経路は非最小位相（単位円外の零点 7 個）。推定経路 Ŝ = S。
- 更新 w ← w − (2B/M) μ Δ。方向 Δ は次のいずれか。
  - SF：Srr の最小位相因子 F で正規化。G = (1/F){R*E/F*}_+（正則化 1e−2·P̄）。
  - B0：Λ = Srr。
  - geo：Λ = √(Srr P̄)（a = 0.5）。
  - GS：Λ = (1−ω)Srr + ω√(Srr P̄)。ω は 0 から 1 への傾斜（4 秒）か、規則で決める。
- Srr と P̄ は EMA（α = 0.05）。g_n = mean|R_n|² / P̄_n。

### 入力（タグは <class>_s<seed>）
| class | 内容 | 主な目的 |
|---|---|---|
| G | 白色ガウス | 定常の基準 |
| PS | パワーの段差（10–15 s で +20 dB、20–25 s で −20 dB） | 尺度がゆっくり変わる |
| BU | バースト（毎秒 50 ms、+20 dB） | 尺度がゆっくり変わる（短い） |
| SM | 対数パワーの正弦変調（周期 1 s、±10 dB） | 尺度が連続して変わる |
| II | ガウス背景に孤立インパルス（約 0.5 s ごと、背景 std の 30 倍） | 尺度が局所的に集中 |
| II300 | 同上、300 倍 | π → 1 の極限 |
| a145、a120 | SαS（α = 1.45、1.2） | インパルス性の雑音 |
| pc | 15 s で二次経路を除く主経路が変化（a145 の入力） | 再収束 |

### 評価量
- Φ 超過：v^T Φ v / J_o（v は Wiener 解 wM からのずれ。pc ではそのブロックで有効な経路の Wiener 解）。毎ブロック記録。理論が直接予測する量。
- L1 ANR（既存の oracle.py の定義：|e| と |d| の EMA の比の dB を時間平均）と L2 ANR（10 log10 Σe²/Σd²）。窓は全体 / 最初の 5 s / 最後の 10%（pc は 15–17 s / 25–30 s / 全体）。
- 発散：w が非有限、または Φ 超過 > 1e8。NaN として扱う。
- dB は負ほど良い。

### 理論の定数（THEORY_vss2.md）
h = (2B/M)·c = 0.25、c = M/N。f ≈ 0.9（実測）。τ_a = 3.8、τ_m = 2.5（既定値。E2 で測り直す）。L = 4、β_d = 0.1（遅延平均）、β = 0.05（C と Q の EMA）。g_min = 0.25。ρ の下限 0.1。

## E1. 最適ステップのオラクルと推定値の比較

**目的**：§2 の推定式 μ̂°(C, Q, μ) が、真の最適ステップを追えているかを確かめる。前半・後半・経路変化の直後で比べる。

**仮説**
- H1a：前半（ずれが大きい）の最適値は、見る長さで変わる。一歩先なら約 1/(h(1+f)) ≈ 2.1、数ブロック先なら 1 前後。
- H1b：後半は一歩先と数ブロック先がほぼ一致し、μ̂° はその値を ±3 dB 以内で追う。
- H1c：経路変化の直後は、μ̂° が数十ブロック以内に前半の値まで戻る。

**手順**
- 規則（SF μ = 0.1、SF+ramp、SF-D g γ0.03 a0 1、GS）を実行し、標本ブロック（前半は密、後半は疎、pc は 15 s の直後を密）で状態 w_n を取り出す。
- その状態から次の3種のオラクルを求める。
  1. 一歩先：そのブロックの実際の方向で μ を格子で振り、一歩後の Φ 超過を最小にする μ。解析解（⟨v, Δ⟩_Φ / ‖Δ‖²_Φ）も記録。
  2. 凍結アンサンブル：係数を固定して K = 32 ブロックの方向を取り、E⟨v, Δ⟩_Φ / E‖Δ‖²_Φ。
  3. T 段の継続：実際の系列で μ を一定にして T = 8 ブロック進め、Φ 超過を最小にする μ。
- 同じブロックで、C、Q（ユークリッドと Φ）、適用中の μ、ψ と μ̂°（a0 ∈ {1, 3.8}、f ∈ {0.9, 1.0}、τ_m ∈ {2.5, 3.8}）を記録。
- タグ：G_s0、a145_s0、a120_s0、pc_s0。

**判定**
- オラクル3種と μ̂° を時間の関数として並べる。μ̂° と T 段オラクルの比の中央値が 0.5–2 の範囲なら「追えている」。
- 一歩先オラクルは構造上 a0 と τ を区別できない（曲率が ‖Δ‖² で決まる）。a0 の決定には T 段オラクルを使う。

**既知の限界**
- §2 の C の式には、ラグ（実効約 13 ブロック）の間の v の変化（hμ×ラグ の次数）が入っていない。Q の式は1次の交差項を落としている。E1 はこの近似の誤差の大きさを測ることにもなる。
- T = 8 の選び方に根拠はない。T 依存性は未調査。

## E2. 相関時間の実測

**目的**：§1 で別々に置いた τ_a（加法的な雑音）、τ_m（ゆらぎ）と、無視した交差項を測る。正規化の種類とずれのベクトルによる違いも見る。

**仮説**
- H2a：τ_a は誤差窓の重なりから約 M/B = 4（三角形の相関）。
- H2b：τ_m は τ_a より小さい（外部の実測 2.4–2.7）。
- H2c：交差項は τ_a N、τ_m S に比べて小さい。

**手順**
- 係数を固定したプローブで、方向を3成分に分ける。
  - ζ：最適残差（wM を使ったときの誤差）から作る方向。平均を除く。
  - ゆらぎ：コヒーレントな誤差（r * v）から作る方向から、その平均 h_eff v を引いたもの。
  - 交差：両者の相関。
- ラグ 12 までの両側和をユークリッドと Φ の内積で求める。
- 方向：SF、B0、geo。ずれのベクトル：−wM（初期）、ランダム、実行後半の v（SF の不動点からのずれ）。
- タグ：G_s0、G_s1、a145_s0、a145_s1。

**判定**：τ_a、τ_m、交差項の比を表にする。THEORY の §1 と §2 の定数を、この値で置き換えるかを決める。

**既知の限界**：後半の v では平均作用がスカラーから大きく外れる（スモークで h_eff 0.09、非スカラー成分 0.4）。§2 のスカラーの仮定がどこまで成り立つかの判断材料にする。

## E3. フレームのゲインと集中度の法則

**目的**：§3 の主張「平均の項は g に比例し、雑音とゆらぎのパワーは g²(1 − π) に比例する」を確かめる。

**仮説**
- H3a：平均の項 / g はフレームによらずほぼ一定。
- H3b：雑音のパワー / g² は (1 − π) に比例する。尺度がゆっくり変わる入力（PS、BU、SM）では π ≈ 0 で、雑音 ∝ g²。
- H3c：孤立インパルス（II300）では、インパルスを含むフレームの雑音 / g² が小さい。

**手順**
- 係数を固定（不動点、および v = −w_fp）し、フレームごとに雑音パワー、平均の項、ゆらぎを計算する。
- π は3通りの窓で計算する。入力 x の N サンプルのフレーム（R_n と揃えた窓）、最後の M サンプル、二次経路を通した参照 r のフレーム。
- g と π で分けたビンごとの表と、回帰（g、g²、g²(1−π)）の決定係数。
- タグ：G、PS、BU、SM、II、a145、a120（seed 0）、II300（seed 0）。方向は SF。

**判定**：g²(1−π) の回帰が g² より明確に良い窓があれば、その窓を手法に使う。どの窓でも改善しなければ、§3 の (1−π) の項は採用しない。

**既知の限界**
- π は σ_t ではなく標本から計算する。ガウスでも下限は約 3/N。
- II（30 倍）はインパルスのエネルギーがフレームより小さく、π ≈ 0.2 にとどまる。極限は II300 で見る。
- 以前の照合スクリプト（pichk.py）は窓が N−B サンプルずれていた。今回は揃えている。

## E4. ステップ則の比較（SF）

**目的**：§3 と §8 の改善案が、性能を上げるかを確かめる。特に「パワーの補正を全区間でかける」効果を、尺度がゆっくり変わる入力で見る。

**比べる規則**
| 規則 | 内容 |
|---|---|
| SF μ.05、SF μ.1 | 固定ステップ |
| SF+ramp | 固定の傾斜（基準） |
| SF-V2、SF-I | これまでの提案（比例型、積分型） |
| SF 1/g μ0 | μ0 / max(g, g_min) |
| SF 1/(gρ) μ0 | μ0 / (max(g, g_min) ρ)、ρ = max(1 − π(1 − ψ), 0.1) |
| SF-D <corr> γ a0 | 直接形（§2）：C、Q の EMA から μ̂° を出し、μ_state ← (1−γ)μ_state + γ clip(μ̂°, 0, 1)。適用は μ_state ×（1、1/g、1/(gρ)） |

γ ∈ {0.03, 0.1}、a0 ∈ {1, 3.8}。

**仮説**
- H4a：PS、BU、SM では、1/g の補正を全区間でかける規則（1/g、SF-D g）が、上限だけの規則（SF-V2、SF-I）より Φ 超過で良い。
- H4b：G では、補正の有無で差がない（g ≈ 1）。
- H4c：II、a145、a120 では、1/(gρ) が 1/g より良い。後半に 1/g をかけるとインパルスのたびにステップを無駄に下げるため。
- H4d：固定ステップの定常の損失は、E[g²ρ]/E[g] で予測できる。
- H4e：SF-D は、ゼロ滞在がほぼない（積分型の SF-I と比べて）。

**手順**：8 クラス × seed 0–2（24 ジョブ、23 規則）。各入力で、予測値 E[g²]/E[g]、E[g²ρ]/E[g] と、実測の定常の超過比（固定 μ と 1/g 則）を並べる。定常の窓は後半（pc は 25–30 s）。

**判定**
- 各仮説について、seed 間の差の符号がそろうか（3 seed すべてで同じ向き）を見る。
- 有用性の判断は L1 と Φ 超過の両方で行う。食い違う場合は両方を報告する。

**既知の限界**
- g は Srr の EMA に対する比なので、段差の後は約 20 ブロックで 1 に戻る。PS では E[g²]/E[g] がほぼ 1 になり、H4a の差は BU と SM で出やすい。
- 3 seed では 0.1 dB の差は判定できない。差が小さい場合は seed を増やす（3、4 を追加できる）。
- g_min、ρ の下限、ψ の初期値（1/(1+f)）、X̂ の切り詰めは理論で決めていない値。

## E5. GS の内積の重みの分離

**目的**：§4 の重みの理論を、ω の制御から切り離して確かめる。前回（GS-T2）は、重み、ω の制御、積分の蓄積が同時に変わっていた。

**手順**
- GS の方向、ω は固定の傾斜（4 s）、ステップは直接形（SF-D と同じ、補正 1/g）。
- 重み：なし / C だけ（Λ/P̄）/ Q だけ（Srr/P̄）/ 両方。a0 ∈ {1, 3.8}。
- 基準：GS（固定傾斜）、GS-V2、GS-T2 fixed-om。
- タグ：G、a145、a120、pc × seed 0–2。

**仮説**：H5：C に重みをつけると、遅いモードのずれが C に現れ、ゼロ滞在が減り、後半の Φ 超過が下がる。

**判定**：重みなしと比べて、ゼロ滞在率と後半の Φ 超過が3 seed そろって改善するか。

## E6. ずれの割合による ω の切り替え

**目的**：§5 の切り替えの指標 ψ^B0、ψ^geo が、B0 の不動点への接近を表すかを確かめ、その指標で ω を閉ループで動かす。

**手順**
- 追跡のみ：B0（ω = 0）を固定 μ = 0.1、または直接形で進め、ψ^B0 と ψ^geo（geo の方向は計算するが適用しない）を記録。同時に、B0 の不動点までの Φ 距離と、wM までの Φ 距離を記録。
- 閉ループ：ω ← EMA_0.05(ψ^geo / (ψ^geo + ψ^B0))、ステップは直接形で、適用する方向 W(0.5, ω) について推定。
- 基準：GS（固定傾斜）、GS-V2。
- タグ：G、a145、a120、pc × seed 0–2。

**仮説**
- H6a：B0 が自分の不動点に近づくと ψ^B0 → 0、ψ^geo は偏りの分だけ正に残る。両者の交差の時刻が、B0 の不動点までの距離と偏りの差 x_b が等しくなる時刻と一致する。
- H6b：閉ループの切り替えは、固定傾斜の GS と同等以上で、経路変化の後に ω が下がる。

**判定**：H6a は交差の時刻と、距離の交差の時刻の差（ブロック数）で見る。H6b は L1 と Φ 超過。

**既知の限界**
- geo の ψ は、適用していない方向について計算する。§2 の hμ の補正にどの μ を使うかは導出から決まらない（実装は適用中の μ_state を使う）。
- GS(ω) の方向は B0 と geo の線形結合ではない（正規化を混ぜている）ので、ω の解釈は近似。
- B0 と geo にも SF の定数（τ_a 等）を流用している。E2 で値が違えば補正が要る。

## 結果の扱い
- 仮説が外れた場合は、理論を直すか、その改善案を採用しない。結果に合わせて仮説を書き換えない。
- 最終評価は別の seed で行う（ここで選んだ設定の過適合を避けるため）。
