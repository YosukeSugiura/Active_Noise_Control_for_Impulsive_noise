# SF+g と SF-ND+g の初期ステップ・長さの比較

- 基準コミットは `615c86068b712ae05d7524e7d51821fec0f97261`。G、BU、PS、II300、a145、a120 の6クラス、seed 10–14 の30入力に各48規則を適用した。各入力は30秒（3,750ブロック）。seed 100–119 は最終評価用。
- 初回の n_e ブロックで内部ステップを μ_e、以後を μ_L とし、全区間で 1/max(g, 0.25) を掛ける。再始動なし。SF-ND は前回と同じ誤差フレームの再構成を用いる。L1 は実誤差に基づく。
- 表1では各試行の区間内で線形 Φ 超過比を平均し、dB に変換する。各指標は有効な seed の dB 平均をクラスごとに取り、クラスを等重みで平均する。数値発散した試行の指標は欠測とし、全 seed が欠測のクラスはその平均から除く。増幅した試行は指標の平均に含める。
- 判定は前回と同じ。数値発散は非有限または Φ 超過比 > 10⁸。増幅は数値発散していない場合の L1 last10 > 0 dB。CSV の経路変化と再始動に関する列は空欄。
- 再現時は `atsip/explore/` で OpenBLAS、OpenMP、MKL を各1スレッドに設定し、`python nodelay_early.py check`、`python nodelay_early.py run`、`python nodelay_early.py report` を順に実行する。実行は最大2ワーカー。試行ごとの中間結果は `out/nodelay_early/`。
